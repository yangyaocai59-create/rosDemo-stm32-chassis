## 重要说明

- 当前 USB IMU 精确数据使用 RAW v2，消息类型为 `0x86`。
- RAW v2 的陀螺偏置单位为 milli-RAW，不能按旧版整数 RAW 偏置解析。
- 当前 MPU6500 已完成精确偏置保存和恢复，但尚未完成温度补偿；不要把它当作长期绝对航向来源。
- ROS2 侧应融合轮速与 IMU 角速度，并通过激光、视觉或其他外部定位源修正长期航向。
- CubeMX 生成代码和当前 `.ioc` 是硬件配置的唯一依据。
