# 落地短行程启停后静止编码器复查

日期：2026-10-12，Asia/Shanghai。结果：本轮未复现；历史后退停车约 33 秒 LF 增加 4 计数的根因仍未确定。

## 测试条件与范围

- 用户确认小车落地且安全，授权低速前进/后退、STOP、静置两分钟。提前说明前后至少 0.5 m 空间、保持清场、异常时切断 VM；查询健康静止状态后倒计时 5 秒。
- 实际板上启动日志版本 `0.13.2-usb-sof-snapshot-fix`，Build `Oct 11 2026 09:04:30`。日志身份校验不等同于 Flash 回读校验。
- COM4：STM32 CDC，USB serial `338536803133`。COM8：用户串口助手记录，不由本工具打开或写入。
- 全程保持单一 CDC 会话；没有复位、烧录、清故障或校准。不修改固件、CubeMX、引脚、方向、轮径/轮距或安全逻辑。
- 只有一组短行程前进/后退，不是历史前后各 80 cm 的同条件复现，也不是地面测距或 PI 参数验收。
- 用户此前报告 VM 开启；编码器供电电压和实际 CCR/使能电平本轮未测量。

## 执行方法

新增主机工具 `Tools/ground_stop_encoder_probe.py`，复用现有协议与 STOP 回归门控，只有 GET_STATUS、VELOCITY、STOP 三类命令。

```powershell
python Tools\ground_stop_encoder_probe.py --port COM4 --boot-log <实际启动日志路径> --ground-safe-confirmed
```

先通过 `--self-test` 验证既有安全状态门控/解码以及新检测器的 +4 后 -4 返回基线事件，语法检查通过，之后执行实板测试。
固定流程：+30 mm/s 0.8 秒 → STOP、等待 2 秒 → -30 mm/s 0.8 秒 → STOP、等待 2 秒 → 静置观察 120 秒 → 最终 STOP 清理。
速度命令约 20 Hz，单段名义目标行程约 24 mm，实际位移并未外部测量。
查询/遥测/ACK 异常、故障、缺失必需 flags 或轮速超过主机安全上限会终止追加速度命令；不自动清故障或重连。退出时尝试 STOP 并核对 ACK/停车。

| 阶段 | LF | LR | RF | RR |

| 前进后计数增量 | +203 | +208 | +199 | +201 |
| 后退后计数增量 | -225 | -234 | -225 | -228 |
| 后退停车并等待后的累计计数 | -22 | -26 | -26 | -27 |
| 静置 120 秒累计计数变化 | 0 | 0 | 0 | 0 |

- 两段均进入 ACTIVE，四轮计数方向符合命令；两次 STOP 后均确认 IDLE/EXPLICIT、请求速度零、四轮 cps 零。
- 静置窗口 2400 帧 WHEEL，间隔 min/max 均为 50 ms，累计绝对计数变化也为四个零，没有观测到逐帧先变后恢复。
- 静置基线 MCU tick 1834259 ms，末次 tick 1954259 ms，跨度 120000 ms。
- 全程 STATUS 1450 帧、WHEEL 2623 帧（含倒计时、运动、停车等待、观察和最终清理）。静止 flags=0x0150；运动观察到 0x0171；未见缺失链路位的 0x0140。
- runtime/controller fault 均零，CRC/RX overflow/TX drop 均零，主机 CRC 错误零；最终 STOP ACK/停车核对通过，工具退出码 0。
- 非零累计值 -22/-26/-26/-27 来自前后运动增量不同，不能把它误判为停车后跳变，也没有人为清零或冻结计数。
- 后续独立重解析记录的原始接收字节及发出帧，验证静置 2400 帧数据、状态、错误计数和速度命令限定为 (+30,0)/(-30,0)，检查通过。

固件现有滤波轮速峰值约为前进 40～41 mm/s、后退 49 mm/s；本轮只记录，不据此宣称速度跟踪、距离重复性或机械标定通过。

## 结论及剩余工作

此前静置基线及本轮落地短行程后静置均未复现异常。它们不能证明历史事件的根因或修复，不排除不同负载/行程/输入条件下发生的低概率事件，也无法排除两帧之间先变后恢复的输入瞬态。

请用户补充 COM8 同窗口日志，建议覆盖 MCU tick 1823000～1956000 ms，包含前后运动、两次 STOP 和整个静置窗口；核对原始 CNT/delta/total 与 USB 累计值。
用户还需确认实车确实前后移动、方向正确且最终停止；本报告中的运动判定首先基于状态及编码器反馈，不替代外部位移观察。
若同步日志无异常，可向 ROS 人员交付“本轮未复现”的只读/实板证据，并保留历史待查项。是否延长行程、重复多组、加诊断固件或电气波形检查，另行确认。
