# 0.18.7 原地转向超速抑制候选固件

日期：2026-10-20（Asia/Tokyo）。版本：`0.18.7-pivot-overspeed-damping`。

状态更新：已完成真实 ARM Debug clean build、离线回归和镜像核验；用户已烧录，完成左右各 6 秒地面对照。用户反馈“更平稳，速度也更均匀”；整体误差下降，但 RR 左转平均速度反而增加，尚未通过后轮跟踪精度验收。详见 [0.18.7 实板证据](stm32_evidence/2026-10-20-v0187-powered-pivot/README.md)。下文参数选择和测试步骤保留为交付记录，不能视为所有验收项已完成。

## 实测依据

[0.18.6 实板证据](stm32_evidence/2026-10-20-v0186-powered-pivot/README.md)显示，左右转向停转占比明显下降，用户反馈更连续，但 RR 在末段两方向平均约 +236.54/-235.31 cps，目标为 ±160 cps；LR 左转均值也达到 -266.62 cps。部分轮子的 RMS 跟踪误差仍偏大。

基线 KP=0.05。当正向目标 160 cps、实测 235 cps 时，P 项仅为 -3.75‰。保留启动后负载支撑的同时，需要评估更强的超速反馈能否压低速度峰值和平均误差。

## 本次改变

新增显式 `WheelSpeedControlMode`：NORMAL 和 PIVOT。普通更新接口仍走 NORMAL；底盘控制器根据与原启动补偿相同的 pivot 条件选择模式（线速度幅值不超过 1 mm/s、角速度幅值至少 10 mrad/s）。

P 项规则：

| 场景 | KP / (‰/cps) |
| --- | ---: |
| 直行、滚动转弯、单轮 PI 诊断 | 0.05 |
| 原地转向：起步、欠速、反向反馈 | 0.05 |
| 原地转向：同方向实测幅值大于目标 | 0.15 |

例如目标 +160、实测 +235，P 项改为 -11.25‰；目标 -160、实测 -235，P 项为 +11.25‰。该数值是基于基线响应尺度的候选参数，不是已完成负载标定的最终最优值。

超速抑制的期望输出限制在目标方向与零之间，避免为了抑制超速而新生成反向驱动力。已有输出历史仍遵守斜率约束，用户明确换向仍经过现有方向保护。误差为零时 P=0，因此超速条件边界不会引入固定幅值的 P 跳变。

继续使用 0.18.6 的 FF/I 补偿交接；KI=0.25、积分限制 ±50‰、总 PWM 限制 ±300‰、输出斜率 1000‰/s、启动补偿 60‰、300 ms 最短保持和 20/50 cps 阈值均未调整。

本次没有改变 CubeMX、引脚、编码器计数/极性、TIM8、USB 报文布局、IMU、校准存储或任务周期。
