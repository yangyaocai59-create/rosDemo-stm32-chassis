# 0.19.1：转向有效轮距模型对齐候选

2026-10-23。保留四轮独立闭环与左右侧目标分配。下文记录离线设计与验证；该镜像现已由用户烧录，已完成三次地面转向。最新校准、断电恢复、左转重复与右转结果见[实测交接入口](stm32_evidence/2026-10-23-v0191-calibration-repeat-right/README.md)。连续执行及编码器重复性已有实测支持，但轮式转角与IMU参考仍约9–10%差异，尚未完成导航验收。

## 改动及依据

此前0.19.0地面测试下发0.40rad/s、主机15秒，编码器按ROS既有395mm有效轮距计算183.62°，主机扣静止基线的IMU参考189.18°，指令积分343.77°。同一计数按固件210mm名义轮距计算345.38°。这支持先消除命令模型与里程计模型的不一致，但没有独立车身转角真值，不能据此宣布395mm已精确标定。

仅四个生产文件变化：

- chassis_config.h：增加独立CHASSIS_EFFECTIVE_TRACK_M=0.395f。物理轮距210mm、轮径65mm、编码器1560counts/rev保持原值。
- chassis_kinematics.c/.h：正向轮速目标分配、反向车体速度估计都使用同一有效轮距。v_left=v-omega*0.395/2，v_right=v+omega*0.395/2。直行目标不变；左右对称；小速度不会被强制抬到0.40。
- firmware_info.h：版本0.19.1-effective-track-candidate。

请求0.40rad/s时：目标由旧约±321变为±603.516cps；0.30对应±452.637cps。轮速/PWM上限、PI增益、FF表和安全判据未变，但同一转向指令对应更高轮速及驱动力，这是实际行为变化，不是单纯显示修正。达到轮速上限时仍按同一比例缩放左右目标，保留曲率；较大的混合线/角速度命令可能比旧模型更早触发限速。

210mm是物理尺寸，395mm是地面滑移转向的有效模型参数，调试启动几何日志中的210mm仍是物理尺寸。ROS实际部署驱动需继续确认使用395mm且无额外角速度倍率，避免重复补偿；本轮没有访问或修改部署中的ROS源码。原始编码器计数上报不经过有效轮距缩放。

## 验证

- 纯运动学strict/O2/fanalyzer：1271组正反混合速度正逆换算、限速、左右轮同侧目标、0.40与0.10rad/s点、直行与异常输入。
- 真实runtime/controller/safety、规定反馈：左右转/时钟回绕下模拟15.2秒目标保持及STOP全轮关断。不是物理轮速预测。
- 原统一算法、事件、trace、故障、编码器及差分回归通过；80k混合与40kNORMAL一致性只说明单轮算法未改，不表示命令轮速仍与旧版相同。
- 完整ARM Debug clean构建，零warning/error；RAM101760B，FLASH180928B，HEX/BIN/向量和地址检查通过。110项生产/Core/USB文件与.19.0源码清单一致，包括IMU、存储、编码器、估计器、驱动和通信；旧.21至.19.0共24个固件文件哈希未变。
