# 0.17.0 左右整圈重复复测

日期：2026-10-17。

**结论：IMU/EKF两方向四次整圈均接近360°；编码器同方向重复差异约4.81°（左）和5.13°（右）。轮速转角仍受明显重复性影响，精确有效轮距标定不通过，参数保持395mm。**

| 动作 | IMU | 编码器 |
|---|---:|---:|
| 左转首次 | +357.32° | +355.07° |

| 右转首次 | -363.42° | -339.64° |
| 右转复测 | -357.14° | -334.51° |

用户每次均确认完整一圈、回到起始方向线、运动和停车正常；参照为人工对齐，角度不确定度未量化。所有记录均使用原0.395m有效轮距，未改轮径、轮距、IMU、固件或安全门控。

左转编码器复测差异：-4.813°；右转：+5.127°。IMU对应重复差异约+0.747°和+6.285°。这表明IMU路径较稳定，而轮速转角受轮胎滑移、带载轮速响应、反馈波动或参照误差等影响；不能通过一个平均比例安全修正。

每轮RAW/ROS样本匹配、源计数连续、协议错误为0，主ACTIVE期间bias固定。复测前另有132秒静止恢复观察，漂移+0.058°/min；左转复测前启动筛查曾短暂出现-1.03°/min并因此禁止运动，随后恢复，说明不能省略静止门控。

右转复测最大cmd接收间隔约311.7ms，但未出现驱动ERROR或安全锁；该点需结合完整日志继续观察，不能将本轮当作通信完全无异常。所有运动结束后进程已停止、串口释放。

## 决定

不修改395mm有效轮距，也不更换IMU。先交给STM32工程师审查带载低速pivot的四轮target/measured、原始编码器计数、PWM/PI/前馈和轮速滤波。ROS侧保持当前解码、融合和安全门控。精确轮距标定、建图、重载定位、导航均未通过。

完整复测证据见各run目录和最终证据包；比较数据见repeat_pair_comparison.json。
