# 0.20.3：原地转向角速度修正候选

2026-10-25。按“均匀、平顺，角度差不多即可”的目标，在 0.20.2 的四轮速度闭环之外增加有限幅、有限变化率的 IMU 角速度修正。本版独立构建，尚未烧录到 MCU，也未完成整机验收。旧版固件、发布包和历史证据保留。

## 行为

- 编码器继续负责四轮速度闭环和原始计数，轮径、395 mm 有效轮距、现有 FF/PI、300‰ PWM 上限、50‰ 轮速积分上限、20 ms 控制周期、50 ms 轮速滤波均未改。
- 仅在纯原地转向、线速度绝对值不超过 0.001 m/s、角速度绝对值 0.12–0.60 rad/s 时启用外环。直行、明显弧线和范围外命令沿用原控制。
- `YawRateControl_Step` 只修正分配给轮速环的角速度，保留原始命令与名义运动整形状态，避免把修正反复累加到下一次参考。
- 修正不超过 ±0.10 rad/s，且不超过当前参考角速度的 25%；变化率不超过 0.12 rad/s²。维持原转向方向，不靠提高输出限制补偿阻挡。
- 角速度使用 80 ms 一阶滤波，候选外环 KP=0.60、KI=0.30/s，有效反馈就绪后等待 600 ms 再修正。积分有界，并处理幅值和变化率饱和。
- 某轮目标与反馈差超过 `max(75 cps, 目标绝对值×25%)`，或轮输出受限时，外环清除积分并撤回修正。保留 gyro 滤波和已完成的等待阶段，避免一个短轮速扰动反复导致 600 ms 重启。
- IMU 失效、样本超过 40 ms、源代次或序列异常时，撤回修正，回退原有轮速控制；本功能不替代已有急停、断链、超时、轮反馈和健康保护。

这些外环系数仍是候选参数，不是已完成的整机辨识结果。修正上限是软角速度边界，原有电气和安全上限继续生效。

## 静止基线和发布

`chassis_yaw_feedback.c` 在 motorTask 中观察同一 IMU 快照。只有电机输出关闭、四轮样本新鲜且净增量为零、滤波速度小于 5 cps、加速度模长在 9.0–10.8 m/s²、无诊断/校准时，才积累 RAM 零偏。

基线至少覆盖 3 秒、100 个不同源样本，Z 标准差不大于 0.003 rad/s。移动期间不学习零偏；源代次变化、非法值、样本跳变或冲突重复会使基线失效。基线未就绪时可使用原有轮速控制，外环不介入。上电或恢复后先保持静止，观察 `YAW3 ready=1`。

没有修改 IMU 服务、持久校准或 Flash。已有校准有效时学习其残余零偏，未校准时学习当前静止偏置；不把运动角速度当成零偏。

每秒 `YAW3` 日志报告 ready/valid、RAM 偏置、去偏角速度、参考、修正、积分、等待时间和轮控制受限标志。USB 既有帧布局和编码器遥测不变。原始编码器角度与 IMU 仍分别保留，未通过改写计数伪造一致。

## 并发与故障记录

外环状态在运行状态快照中复制，在临界区外计算；只有运动代次和命令修订仍匹配，且原控制器接受新命令时才提交。STOP、断链、超时、健康故障和急停均清零外环状态，旧计算不能恢复输出。

另外修复重复健康故障锁存：已处于健康故障、控制器已关闭时，safetyTask 的后续调用不再每 10 ms 重写运动代次和事件环。保留首次故障现场；未取消锁存、保护或清故障条件。

## 测试与证据

新增主机测试覆盖静止基线、噪声、移动、NaN、重复/跳变/源重启、时间回绕、双向修正、限幅/斜率、失效回退、反转、零命令、轮反馈不足、执行受限、Stop 打断计算、重新启动无残留以及重复健康故障记录。简单一阶模拟仅验证算法性质，不当作实车表现。

还使用同一 C 核心编译的 Windows DLL，通过现有 USB 接口做上位机验证。板上仍为 0.20.2；上位机验证不等于 0.20.3 MCU 集成验收。原始采集、使用过的 DLL、各次系数和失败记录保存在 `docs/stm32_evidence/2026-10-25-v0203-yaw-assist` 与 `2026-10-25-v0203-host-obstruction`。

首次试验被线缆阻挡，LF 保护锁存，立即停车。用户确认原因解除后，在四轮零速和正常供电下仅清除一次故障；没有把该记录删除、归因于控制器或弱化保护。随后分别保留左转保守参数和右转修订参数的数据，不用两种方向和不同条件简单宣称改进百分比。

## 独立构建

- 宏 `CHASSIS_CONTROL_REVISION=203`。
- 配置 `WheelV0203Debug`、`WheelV0203Release`，各自使用独立构建目录。
- 归档 `build/firmware/0.20.3/{Debug,Release}/rosDemo-0.20.3.{hex,bin,elf,map}`。
- 发布 `releases/0.20.3/rosDemo-0.20.3-offline-candidate.zip`，含源码、验证及校验和。
- 默认 Debug/Release 仍为 191；旧的 200/201/202 配置保留。

```powershell
python -B Tools/package_wheel_v0200.py --version 0.20.3
```

打包强制执行 strict/O2/fanalyzer、新旧 USB、191 兼容、Debug/Release clean 构建、HEX/BIN/地址/版本/内存检查、受保护源文件及所有旧产物哈希复核。实际结果在交付包的 `verification.json` 和验证日志中，构建成功不能替代烧录后的 ±10% 匀速目标及 ±2° 定角目标复测。

本版加入的是角速度外环，没有新增 MCU 定角命令。此前 180° 仍由主机积分 IMU 后发 STOP；上位机定角演示和 MCU 固件能力明确区分。
