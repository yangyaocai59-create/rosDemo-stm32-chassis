# 0.18.14 前轮持续超速确认候选

日期：2026-10-21（Asia/Singapore）。版本：`0.18.14-front-load-confirm`。

状态：用户批准的窄范围修改已完成，35 项运动回归、20 项 USB 回归及 ARM Debug clean build 均通过，镜像校验通过。随后用户报告已烧录，[只读检查](stm32_evidence/2026-10-21-v01814-postflash/README.md)正常，[架空左右转](stm32_evidence/2026-10-21-v01814-lifted-pivot/README.md)现场连续且末段撤载正常，但仍有起步超调。经另行确认的[一次落地右转](stm32_evidence/2026-10-21-v01814-ground-pivot/README.md)两前轮均不流畅、RF 反复近零后超速，性能验收不通过。已正常 STOP 停车，没有清故障/自动重试，不发布为稳定版。版本身份依据用户烧录报告，未捕获启动版本行；不能宣称欠速或停顿已解决。

## 为什么修改

后续离线审计：[0.18.14 临时补力—稳态支撑交接复核](stm32_evidence/2026-10-21-v01814-handoff-review/README.md)用未修改的原C探针及条件性初值重建复现交接缺口，PWM逐帧与两前轮记录吻合；提出合成预算内的可撤回交接设计要求，尚未实现/编译下一版。此审计不改变本版落地验收失败的结论。

[0.18.13 欠速复核](stm32_evidence/2026-10-21-v01813-underspeed-review/README.md)确认：RF 目标约 160.428 cps，末段平均约 115 cps，但 7 次短时超速触发的名义撤载约 28‰，几乎抵消约 28.02‰ 的普通积分修正，FF+I 净支撑基本不增。该结果揭示控制策略改进点，但不是所有停顿的物理根因诊断。

本版不同时增加欠速增益或额外补力，只避免短时波动反复触发快速负载撤减。

## 实际改变

仅前轮 LF/RF 的 PIVOT 策略有效，沿用 |vx|≤1 mm/s、|wz|≥10 mrad/s 和轮目标幅值≥20 cps 的入口条件。直行/滚动转向、后轮策略不使用新计时。

1. 沿用原超速判据：同向反馈比目标幅值高于 `max(20 cps, |target|×10%)`。严格大于，等于阈值不满足。
2. 新增局部 `load_overspeed_ms`，按有效 dt（1..100 ms）累加连续超速，饱和在 60 ms；任一不满足判据的采样清零，不累计分散脉冲。
3. 只有连续超速计账达到 60 ms，才执行原有 200‰/s 的负载撤减及原有反向积分债务交接；负载仍能撤到零。
4. **现有 P 超速阻尼和正常 I 回退不等待这个计时。临时 recovery 遇到超速仍立即终止主动阶段、按原速率渐退，也不等待新计时。** 不把“等负载撤减”变成“等所有减力措施”。
5. 模式退出、换向、目标低于入口、零目标及 Reset/STOP 清理局部计时；invalid dt 不推进状态。换向后按新方向重新计账。

60 ms 是有效控制步计账，不是独立硬件定时器：20 ms 周期下第三条连续超速记录开始撤减，三条记录首尾相差 40 ms；首次达到门槛的更新仍按整步 dt 执行原速率，没有事后补跑循环。若单步 dt=100 ms，本步计时饱和并按该有效步执行有界撤减；>100 ms 的原时序故障行为不变。

新增状态为每槽 4 B，四槽数组共 +16 B RAM，不是 USB 协议字段。没有更改 wire 长度、消息号、trace 格式或 ROS 解码规则。

## 没改什么

- P/PI 参数、FF 标定、负载上限、临时补力峰值、积分上限、PWM 上限及斜率均未提高，命令目标速度不变。
- 0.18.13 的 1500 ms 连续近零且恢复耗尽故障、故障锁存、整车输出关闭路径保留；没有自动清故障或重试。
- STOP、零命令、250 ms 命令超时、真实 USB/SOF/DTR 断链、急停、任务健康、IWDG 保留。
- 编码器/滤波、后轮、直行/运动整形、USB、IMU、校准存储、引脚及 CubeMX 配置未改。

生产源码相对 0.18.13 仅修改：`wheel_speed_controller.c/.h`、`wheel_speed_control_config.h`、`firmware_info.h`。`fault_manager.c/.h`、`chassis_controller.c`、驱动及 USB/IMU 等文件与 0.18.13 manifest 哈希一致。

注意：上限不变不等于每一时刻 PWM 都与旧版相同。短时超速期间保留负载支撑，输出可能比旧版高，架空卸载峰值/连续超速响应仍必须先实测，不能只凭离线固定反馈断言闭环稳定。
