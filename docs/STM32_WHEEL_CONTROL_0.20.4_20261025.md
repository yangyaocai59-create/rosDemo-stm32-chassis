# 0.20.4：保留减速能力的转向修正候选

2026-10-25。独立版本，在 0.20.3 的基础上调整轮速异常时的角速度修正规则。0.19.1、0.20.0、0.20.1、0.20.2、0.20.3 的镜像和发布包均保留，不覆盖。整版 0.20.4 尚未烧录，仍需 MCU 集成复测。

## 原因与行为

0.20.3 同一 C 核心的上位机试验中，右转去掉起步 1 秒后的完整 1 秒窗口最大角速度偏差 7.65%，左转为 19.61%。这不是同条件重复试验，不能据此宣布改善比例或双向达标。轮速跟踪偏差较大时，旧外环清除积分并把所有修正退回零；其中也包括原本正在降低过高角速度的修正。

0.20.4 在轮速跟踪偏差超过 `max(75 cps, 目标绝对值×25%)` 或输出受限时：

- 清除角速度外环积分，禁止新增任何同方向加速补偿。
- 有效 IMU 显示角速度过高时，允许比例项降低名义转速。
- 原有加速修正先按变化率限制撤回，经过零后才逐步减速。
- 保留 600 ms 等待期、±0.10 rad/s 且不超过参考值 25% 的修正上限、0.12 rad/s² 变化率上限，不反转名义转向。
- IMU 无效时仍逐步撤回修正；已有轮反馈、堵转、急停、断链和超时保护继续独立运行。

减速补偿是减小目标角速度，没有放宽 PWM 或电流保护，也没有改写编码器计数。轮子持续不动仍由既有保护停车锁存，不自动清故障。

## 延续 0.20.3 的范围

外环仅用于线速度绝对值不超过 0.001 m/s、角速度绝对值 0.12–0.60 rad/s 的纯原地转向。KP=0.60、KI=0.30/s、角速度滤波时间常数 80 ms。四轮原有 FF/PI、300‰ PWM、50‰ 轮速积分、20 ms 控制周期、50 ms 轮速滤波、395 mm 有效轮距和传感器/存储/USB 协议均保留。

启动后需静止至少 3 秒建立 RAM 陀螺零偏，观察 `YAW3 ready=1`；IMU 样本需新鲜且有效。基线失效时仍可使用原轮速控制，外环不介入。没有更改 IMU 持久校准或新增 MCU 定角命令。此前 180° 演示由主机积分 IMU 并发 STOP。

名义运动整形状态与修正分开保存，计算在临界区外进行，提交时校验运动代次和命令修订；STOP、断链、超时、故障和急停清空外环。继承 0.20.3 对重复健康故障事件刷屏的修复。

## 验证与使用

主机测试新增双向轮速受限时的超速减速、禁止增力、积分清零、等待期、已有加速补偿过零和变化率检查；包含真实 runtime 与 controller 的集成夹具。简单模拟模型不代表实车性能。

同一 C 核心编译为 Windows DLL，通过现有 USB 进行有限时转向试验；板上仍为用户已烧录的 0.20.2。上位机传输和调度与 MCU 存在差别，这些试验不能替代新版 MCU 上的 `YAW3`、实时性、停车路径和匀速复测。原始采集、源代码、DLL、角速度窗口分析及失败记录保存在 `docs/stm32_evidence/2026-10-25-v0204-yaw-assist`；前面的参数试验及线缆阻挡记录分别保留在两个 0.20.3 证据目录。

实际硬件结果见上述证据目录的 README 和 `yaw_uniformity.json`。评价方法为源时间积分，排除起步首秒与最后不足一秒；不能把平均总角度接近目标视为全程均匀。±10% 匀速、180° ±2° 仍需烧录后的双向重复验收。

独立构建：`CHASSIS_CONTROL_REVISION=204`，预设 `WheelV0204Debug` / `WheelV0204Release`，默认旧配置仍为 191。打包命令：

```powershell
python -B Tools/package_wheel_v0200.py --version 0.20.4
```

产物为 `build/firmware/0.20.4/{Debug,Release}/rosDemo-0.20.4.{hex,bin,elf,map}` 和 `releases/0.20.4/rosDemo-0.20.4-offline-candidate.zip`。打包强制执行 strict/O2/fanalyzer、191 兼容与新旧 USB 回归、Debug/Release clean 构建、镜像/内存/版本校验及受保护源码与全部旧产物哈希复核。实际离线检查结果以包内 `verification.json` 与验证日志为准。
