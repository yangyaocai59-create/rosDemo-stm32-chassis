## 3. RR 事件与补偿

详见 event_review.json、all_wheel_timeline.csv：

- 窗口开头 RR dc=0、滤波速度16→0，PWM仍148→169‰，未被 STOP 或输出撤零。FF125.2→145.5‰，I约11.3‰保持不变，未到积分50‰或PWM300‰上限。
- 162682 ms开始重新计数（dc=1）；162722 ms dc=5、滤波99 cps。162742..162782 ms FF每帧减0.8‰、I每帧加0.8‰，与有界补力到I转交相符，不是同时叠加两份支撑。
- 162802 ms滤波273 cps超过目标，FF143.1→135.1‰，随后每帧减8‰；162902 ms FF已回到约96.8‰基础值。这与新策略首个滤波超速样本撤减的设计相符。
- 但轮速随后仍达到约349 cps；USB全程峰值463 cps。162762 ms原始dc=7（350 cps）时滤波仍191 cps，提示**滤波观测滞后/恢复动力学值得继续分析**，不等于确定唯一原因。
- 末段 RR 的 FF+I 最大单步变化8.4‰，旧 .19 对照为47.6‰；说明记录中的大补偿阶跃减小，**不等于实际停顿被消除**。

trace 没有直接上报 RR 私有所有权、episode 或临时A字段；不能仅由打印前馈反推唯一私有初态。RR缺口与LF缺口部分交叠，不能确定因果方向，也不能排除机械/电气或四轮负载相互作用。
