# 0.18.23 架空左转0.30 rad/s、15秒

2026-10-23，Asia/Singapore。用户确认架空、允许0.30rad/s且正常情况下至少15秒；异常保留立即停车。首次尝试缺电失败后，用户明确说明“VM刚刚没有打开，现在打开了可以重新执行了”。本轮未修改、编译或烧录固件；板上版本依据用户烧录声明及TRACE2字段，未主动复位读取启动版本或读回Flash。

## 两次尝试分别保留

- `power_off_attempt/`：VM遥测3.520～3.707V，约1.593秒时LR健康保护锁存，其他轮反馈也接近零。79帧TRACE2完整。没有把它解释成正常供电下的控制性能失败。首次失败未自动清故障/重试，用户纠正供电后才进行下一次。
- `powered_repeat/`：先测到10.846V，检查控制器关闭且四轮零速后清一次已知缺电故障，再核对IDLE。一次架空左转0.30rad/s正常运行15.000秒，238条速度命令接受，新增拒绝0。STOP得到ACK，最终IDLE/EXPLICIT，fault=0/0、flags=0x0150，四轮零速；停车帧软件STBY、GPIO STBY与四路CCR均为0。两端口已关闭。

这次供电完整采集范围10.747～10.879V，包含静止/运动/导出阶段，不能全部当作运动电压范围。CRC/RX overflow/TX drop均无新增且为0。UART记录motor_dt=20..20ms、safety_dt=10..10ms，没有新增周期超限；运行日志电机栈余量1192字节，安全任务336字节，是本次观测而非所有工况最坏界限。

## 新记录功能验证通过，轮速跟踪未通过

128帧完整导出，reason=2（正常STOP）、mask=0（没有诊断持续欠速触发），全部快照flags=0。保留的ACTIVE段源时间382223～384743ms，约2.52秒，另有停车帧。无欠速触发时依设计保留尾段；不能用这一段宣称全15秒每个20ms原始区间均已观测。

尾段127帧的方向归一均值（UART显示整数，均值亦为近似）：

| 轮子 | 目标cps | 滤波反馈cps | 平均PWM‰ | 同向积分‰ |
| --- | ---: | ---: | ---: | ---: |
| LF | 240 | 480.3 | 84.7 | -50.0（全127帧达到下限） |
| LR | 240 | 241.3 | 49.9 | -35.7 |
| RF | 240 | 521.9 | 86.0 | -50.0（全127帧达到下限） |
| RR | 240 | 241.2 | 53.6 | -43.2 |

四轮尾段都没有dc=0，驱动请求与接受PWM一致，CCR也有对应的非零预装载值。采集全程净累计变化LF/LR/RF/RR为-6933/-3753/+7661/+3778，包括停车余动及静止采集阶段，不直接当成精确15秒平均速度。

前轮原始反馈均值同样约480.7、522.4cps，不能只归因于50ms滤波延迟。真实输出由FF+P+I组成：例如LF反向FF约146.6‰，方向归一P约-12‰、I=-50‰，最终仍约84～85‰；RF同样被现有I下限限制撤力。说明当前FF与有限积分校正范围不适配此架空工况，是本轮已有数据支持的控制局限；全局300‰上限在这里无关。

这与之前的“带载可能补力不足”并不矛盾：同一组固定前馈和±50‰积分，在低阻力时可能撤力不够，在高阻力时可能加力不够。架空数据不能直接决定落地应把FF降低多少，更不能据它唯一解释历史带载计数平台。

## 后续判断

1. 不以本次完整15秒且无故障宣布速度精度/ROS转角验收通过。
2. 先根据已保存的四轮原始速度与PWM建立空载/带载参数需求差异，评估统一算法内FF与双向积分校正余量、抗饱和，避免直接叠加按轮恢复脉冲或只提高PWM。
3. 本轮只左转，另一方向及带载响应尚未验证。没有自动追加右转或落地动作；当前车体仍由用户确认处于架空状态。
4. 正常转向测试默认0.30rad/s、计划15秒；故障/断链/现场异常立即提前停止，不能为满足时长绕过保护。
