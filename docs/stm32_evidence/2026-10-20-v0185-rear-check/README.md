# 有电池供电的 RR/LR 架空对比，2026-10-20

本目录数据来自原板上 0.18.5 测试，不是 0.18.6 的实车验收。测试条件：用户确认四轮架空固定、电池开启；电脑直连 CDC COM4 / CH340 COM8，USART1 115200 8-N-1。

## 相同 PWM 点动

15% PWM、800 ms，每轮每方向重复三次。固件全部报告完成。

| 轮子 | 正转增量/count | 反转增量/count |
| --- | --- | --- |
| RR | 763 / 775 / 776 | -737 / -745 / -752 |
| LR | 765 / 760 / 764 | -793 / -815 / -831 |

RR 正向均值 771.3 counts，LR 763.0 counts；RR 反向幅值均值 744.7 counts，LR 813.0 counts，差约 -8.4%。这包含启动过程和有限测量窗口，不是同电压稳态转速精确标定，也不能单凭该差异判定故障。

原始文件：`pulse_results.json`、`pulse_ch340.log`。

## 相同目标速度闭环

现有单轮诊断：+500 cps 4 秒、停稳、-500 cps 4 秒、停稳。每方向的固件统计均取最后 2 秒，共 100 个控制样本。

| 轮子/方向 | 目标/cps | 平均/cps | 范围/cps | 最大 PWM/‰ |
| --- | ---: | ---: | --- | ---: |
| RR 正向 | 500 | 519 | 508…528 | 150 |
| RR 反向 | -500 | -508 | -527…-500 | 150 |
| LR 正向 | 500 | 509 | 501…525 | 136 |
| LR 反向 | -500 | -508 | -526…-500 | 140 |

最大 PWM 来自固件阶段统计，不能当作末段平均 PWM。全部测试完成，无中止。用户现场确认“转动连续，只是声音不同”。主机没有录音，因此没有进行声学或齿轮箱故障诊断。

原始文件：`pi_summary.json`、`pi_ch340.log`。

结束后只读状态：IDLE/DIAGNOSTIC，四轮速度为零，flags=0x0150，fault=0/0，CRC/RX overflow/TX drop=0；供电遥测约 10.79 V。

当前证据未显示 RR 编码器丢计数、方向错或单轮闭环无法跟踪。不需要仅因声音不同立即交换接线或判定 RR 损坏；无法排除仅带载时出现的机械问题。

复测前一次连接异常已单独处理：主机见 USB VID/PID=0483:DF11 的 STM32 BOOTLOADER，应用没有运行。没有擦除或烧录；用户恢复正常启动后，才采集本目录有效结果。采集程序先设置 CH340 DTR/RTS=false，再打开串口，并检查新鲜运行日志才允许点动。
