# 0.18.10 有电池地面 pivot 对照，2026-10-20

结论：用户反馈“更连续，突然加速减轻”。后轮短时补偿确实逐步退出、不再在退出时整段填入积分；RR 左转峰值和 RMS 下降。但左转 LF/LR 长零计数、右转 LF 末段欠速仍存在，右转 RR 峰值反而上升，不能标记全车控制通过。本轮没有修改或烧录固件，也没有追加运动测试。

## 条件与身份

- 用户报告烧录 [0.18.10](../../STM32_REAR_TRANSIENT_ASSIST_0.18.10_20261020.md)。未回读 Flash、未重新捕获 Boot Banner；后轮短时 FF 每周期约减 4‰、I 不跳至上限的 trace 行为与候选一致，但不是独立二进制身份认证。
- 先只读 GET_STATUS，确认 COM4/COM8、IDLE、四轮静止、fault=0/0、供电约 10.725 V。用户确认四轮落地、约 80 cm 空间、无人接触，可以测试。
- 左右各一次，vx=0，wz=+200/-200 mrad/s，各 6 秒、20 Hz 指令，每方向 120 条。每次 STOP 并读完 TRACE END 后继续。
- CH340 在 open 前设置 DTR=False、RTS=False，测试中保持连接，没有主动复位。
- 左转供电遥测 10417..10736 mV，右转 10428..10758 mV。与上一版测试间隔数小时，摩擦、摆放、负载及温度未被严格控制；不能把单次差异都归因于代码。
- 每方向取得 128 帧 trace：127 ACTIVE、1 STOP，完整四轮数据，源间隔恒定 20 ms。左 ACTIVE 时间 57202..59722 ms，右 96122..98642 ms，均只覆盖末段约 2.52 秒；全程另有 USB 计数/速度。

四轮 RMS 误差简单均值：左 106.06→97.25 cps，右 66.40→48.55 cps。总体下降不能掩盖左转 LF/LR 退化及右转 LF 的持续欠速。

RR 绝对滤波峰值：左 495→311 cps，右 254→312 cps。因此不能表述为“RR 双方向峰值都下降”。左转 LF 平均虽然接近 -160 cps，仍有停顿和高速阶段交替；右转 LF 平均 +112.13 cps，约比目标低 30%，积分几乎全窗处于 +50‰ 上限。

全程 USB 2..6 秒平均 LF/LR/RF/RR：

- 左 `[-164.18,-170.96,+204.94,+169.36] cps`。
- 右 `[+162.86,+184.80,-195.53,-171.86] cps`。

右转 LF 的 2..6 秒均值与末段均值明显不同，不能用一个整段均值声称速度稳定跟踪。

## 零计数区间

| 左 | RF | 6.30% | 10.24% | 160 | 140 |

*本次 RR 左转最长 200 ms 区间位于 trace 末尾，停车前没有观察到恢复。只能报告本窗口所见，不把它当成未来继续运行时恢复只需 200 ms 的证明。也不能把约 2.52 秒窗口的零计数占比称为整次 6 秒占比。

四轮平均零计数占比：左 11.03%→20.67%，右 5.71%→3.35%。右转更连续，但左转局部退化明显，与用户整体感觉改善可以同时成立。

左转 LF 57342..58082 ms 连续 38 帧 dc=0，滤波速度由 -74 趋近 0，PWM 从 -161 增至 -188‰，积分为 -50‰。LR 57602..58062 ms 连续 24 帧 dc=0，PWM 从约 -97 增至 -175‰，随后恢复计数。两者都是完整记录到恢复的长区间，不是单个低速量化零值。

这些记录显示：恢复运动时 FF 每个 20 ms 样本下降约 4‰，积分只按误差小幅变化，没有在退出时额外填到 ±50‰。右转 RR 首帧实际 PWM 仍增大，是上一输出斜率限制尚未追上期望输出，并不等于短时 FF 没有退出。

设计方向得到行为证据支持，但没有证明所有停顿和超速都由这一个交接问题造成。首次起步/前轮保留的旧支撑、未完成带载标定的前馈、机械摩擦及四轮耦合等仍需区分。前轮代码未直接改动，也不能据此把其行为变化自动排除在整车影响之外。

下一步建议先保留本版分离机制，以左侧带载起转/维持输出和前馈核对为重点，采用有边界的针对性诊断；不要只因总体均值更好就发布为最终稳定版，也不要直接统一提高全车 PWM、积分上限或修改 ROS 轮距来掩盖误差。

## 通信和停车

- 240 条速度指令最终全部接受，拒绝 0；fault=0/0。
- 主机 CRC=0；固件 CRC/RX overflow/TX drop=0。
- 控制日志 motor_dt=20..20 ms、safety_dt=10..10 ms，overrun=0/0、log_drop=0。
- 两次 STOP 后均确认 IDLE/EXPLICIT，请求速度和四轮速度 0。
- 最终 STATUS 源时间 132449 ms，flags=0x0150，四轮速度 0。
- 本轮没有重做物理拔线、急停或掉电测试。IMU bias=0，本次未校准，也未据此验收角度；交 ROS 使用前仍需显式校准保存。
