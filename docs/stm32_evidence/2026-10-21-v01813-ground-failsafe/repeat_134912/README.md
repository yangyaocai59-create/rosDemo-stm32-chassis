## 结论与边界

同固件、相同命令的两次落地结果不同：上一轮 RF 持续近零后触发保护，本轮 RF 现场连续且未满足持续近零条件，因此不应触发同一保护。此次提供“成功清故障后可重新接收新命令、连续运动不误触发、STOP 正常”的实板证据，**不代表跟踪性能通过或故障根因已排除**。

本版只补足恢复失败的关断路径，没有解决所有带载欠速。变化可能来自轮位/接触/摩擦/供电或控制器内部负载补偿随反馈演化；本组没有独立控制这些变量，不能据两次差异断言唯一原因，也不能据一轮正常继续自动清故障重试。后续若继续，应先设计能区分这些因素的最小对照，不自动提高 PWM 或改编码器/IMU/USB。
