# 0.18.16 同固件落地 ±300 mrad/s 对照

时间：2026-10-21 19:45:14，Asia/Singapore。用户明确确认落地、电源开启、约80 cm空间、线缆可随车转动且不缠轮/拉紧、手远离车轮、串口助手及ROS关闭，授权左右各最长6秒，中间停车，异常终止且不清故障重试。

现场反馈：**“更连续、更均匀，没有明显异常”**。

结论：提高目标速度对本次左侧轮连续性及右转RF最长零计数有帮助，支持把0.30 rad/s作为后续人工试验档位；但RF仍欠速/间歇零计数，左转RR仍超调，不足以声称“ROS使用无误差”或整车控制全部通过。没有把ROS小指令自动放大，没有设置固件最低转速，没有提高PWM上限。

## 与此前200右转的有限比较

此前.16单次200右转见[基线记录](../2026-10-21-v01816-ground-pivot/README.md)。现在目标从160提高到240 cps，两次供电/摆放/摩擦条件未严格控制，没有200左转同版落地基线。

- 右转LF最长零计数260→0 ms、LR160→0 ms、RF220→140 ms、RR20→0 ms。
- 右转LF/LR/RR均速误差明显缩小；RF仍约欠目标17%，左转RF末段约欠24%、RR约快27%。这些是末段均值比例，不代表每瞬间速度或车体角度误差。
- RF右转RMS绝对误差76.46→80.16 cps；目标变大时不能只看绝对误差宣布改善或退化。其均速绝对误差79.57→40.85 cps，但仍有间歇计数停止。
- 改善支持“较高目标可能避开部分低速困难区”的方向，不证明任何更高速度都更好，也不证明硬件或控制已无问题。

## 后续边界

保留本次结果，不追加运动、不自动加到350、不继续提高PWM上限、不烧录。0.30 rad/s可作为人工遥控候选速度而不是强制最低转速；ROS给0.20时不能擅自执行0.30。下一步如继续，应先离线聚焦RF恢复及左转RR超调，区分PWM/FF/P/I时间关系。若用户接受一定跟踪误差，也需明确使用范围；不能把单次流畅反馈写成全工况长期稳定或里程计无误差。
