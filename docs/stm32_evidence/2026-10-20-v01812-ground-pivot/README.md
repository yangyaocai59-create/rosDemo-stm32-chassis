# 0.18.12 落地原地转向证据

日期：2026-10-20（Asia/Singapore 显示时区）。候选固件为用户报告已烧录的 `0.18.12-front-pivot-adaptive`。车辆落地，电机电源开启；每次 6 秒，20 Hz 发送速度命令，结束后 STOP 并确认 IDLE。没有修改或重新烧录固件。

**2026-10-21 复核更正：** 已用真实生产代码离线复现“恢复耗尽后 PWM=-133‰、I=0、160 cps 不进入堵转检测”。此前优先归因机械过早，现有证据不能排除固件控制/保护设计限制。右转零计数累计/连续时长、第二次左转均速及低速表格已更正；详见[源码与数据复核](../2026-10-21-v01812-front-rest-audit/README.md)。

## 已完成测试

- 左转 +350 mrad/s：两次。用户观察第二次右前轮连续、无明显异常；RF 末段均速分别 +240.99/+253.04 cps，目标 +280，RF 零计数帧均为 0。
- 右转 -350 mrad/s：两次。第一次 RF 平均约 -127 cps，累计 36 个零计数帧=720 ms，最长连续段 380 ms；第二次 RF 平均约 -205 cps，累计 16 帧=320 ms，最长连续段 160 ms。两次均有右前轮明显欠速，但没有新的同步肉眼反馈，不能据此确认物理停轮或声响。
- 右转 -200 mrad/s：第一次采集在 trace 导出阶段中断，板上随后只读状态确认 IDLE/零速/无故障，不采用其不完整数据。第二次完整采集：RF 末段 127 帧全部为 0 cps，目标 -160 cps，PWM 平均 -133‰；其余轮为 LF +120、LR +156、RR -182 cps。
