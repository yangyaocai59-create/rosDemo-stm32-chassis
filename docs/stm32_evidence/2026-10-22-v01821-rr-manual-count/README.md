结果支持 RR 基本轮号、方向和1560 counts/圈倍率配置合理，未发现明显倍频或映射错误，暂不修改编码器比例。但这不是1560精密标定，也不证明带电/带载运行时没有漏采，更不表示前次140ms RR反馈间歇已解决。

- USB 三个停稳端点的 RR 累计值1639/6328/1647，与同期 CH340 `ENC R ... RR total=`完全相同。
- RR TIM4原始16位值63897→59208→63889：正向减少4689、反向增加4681，与固件RR归一化符号−1一致。这里只核对实际增量和取模一致性，未独立测试计数器跨零/溢出的全部边界。
- 全部2698个USB轮状态帧中，LF/LR/RF累计值始终为−850/−1709/+1326，没有串轮变化。
- 从保存的原始USB字节独立重解码，所有轮状态与采集时记录逐项一致，CRC=0。
