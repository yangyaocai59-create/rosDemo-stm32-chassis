# 0.18.12 两次架空左转

日期：2026-10-20（Asia/Tokyo）。用户报告烧录完成，随后确认四轮架空固定、电池/电机电源开启、人员与线缆安全、串口助手关闭。第一次结束后用户忘记观察，明确要求再做一次；第二次实际反馈：“一直连续，没有明显异常”。

## 条件与边界

- 候选 `0.18.12-front-pivot-adaptive`，未再次修改、编译、烧录或主动复位。未捕获新 Boot Banner，版本身份依据用户烧录报告，不声称做过 Flash 回读认证。
- COM4 CDC / COM8 CH340；打开 CH340 前 DTR=False、RTS=False，同一次运动及 trace 导出保持连接。CDC DTR=True。
- 两次均 vx=0、wz=+350 mrad/s、6 秒、20 Hz / 120 条速度命令；物理架空仅为采集元数据，不改变控制。四轮目标 LF/LR=-280、RF/RR=+280 cps。未抬高请求速度。
- 每次先 STOP/GET_STATUS 核对 IDLE、零速度、无故障和供电范围；运动结束立即 STOP，确认停车后才读 trace。第一/二次供电预检 10714/10725 mV，运动范围 10637..10725 / 10648..10725 mV。
- 对照为 [0.18.11 同目标架空](../2026-10-20-v01811-rf-lifted-compare/README.md)，供电 10692..10780 mV。不是完全相同温度/电压或交替 A/B 多次统计，不能把全部差异都当作严格实验因果估计。
- 每次 128 帧 trace：127 ACTIVE + 1 STOP。ACTIVE 时间第一次 285042..287562 ms，第二次 363402..365922 ms，间隔均 20 ms，覆盖末段 2.52 秒，不是完整 6 秒均值。全程另有 USB 采集。
