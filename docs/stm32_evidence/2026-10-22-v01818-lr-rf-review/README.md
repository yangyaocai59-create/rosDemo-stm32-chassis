## 冻结真实C的条件性回放

冻结13个源码/头文件，与交付清单逐项核对。`replay.c`包含未改的`chassis_controller.c`和`wheel_speed_controller.c`，采用相同运动学目标、20 ms/50 ms低通及200 ms停转规则，输入原始dc。不是另写Python控制器去复述结论。

环只保留末2.54秒，开头已有运动，无法从零状态恢复整段私有历史。因此：

- 第一帧作为**更新后的初态**，滤波速度和I取打印截断区间中点，PWM取打印值；之后126帧才用于输出对照。
- LR起始总bias为0、已确认运动；更早的首次起步/恢复历史不可观测，不宣称已读取板上私有状态。
- RF假设起始临时恢复为0，load由打印总FF减基础FF推定，方向/运动状态依记录。该分解是可解释后续输出的假设，不是唯一隐状态证明。
- 对初态在打印量化区间内作低/中/高三组扰动，不逐帧调参、不重新拟合输出；它是有限敏感性检查，不穷尽所有历史。

三组均通过：每轮后126帧的打印PWM与记录最大差1‰，FF/P/I最大打印差1个x10单位即0.1‰，反馈最大差1 cps。中点LR125/126、RF124/126个PWM完全相同，其余差1‰。原生编译`-Wall -Wextra -Werror`通过，无警告/错误；只生成主机诊断EXE，不生成新MCU固件。

### LR：近停门槛后的恢复比较集中

真实后轮路径位于`source_snapshot/chassis_controller.c`：

1. 运行中的后轮仅在滤波同向速度≤20 cps时重新进入恢复。原始计数已为零时，低通还从175.7依次衰减至125.5、89.6、64.0、45.7、32.7、23.3、16.7 cps；到第七个零样本才跨入门槛。
2. 回放在542863 ms进入运行后restart。此前I约+1.42‰，与反转目标相反，无法抵扣同向补力，因此加入原60‰权限，使FF从约-85.7变成-145.7‰。
3. **实际PWM没有一步跳60‰。** 现有1000‰/s斜率仍限制为20 ms最多20‰，所以-95→-115→-135→-154。期间I保持原值可由斜率抗积分饱和分支解释，不是USB没更新I。
4. 542903速度仅约37.1 cps，虽已满足40 ms最短保持，但未达50 cps释放门槛；542923约83.6 cps时释放，恢复实际持续60 ms。
5. 运行恢复项随后以200‰/s，即每20 ms撤4‰，不是转存到稳态I。在LR反馈约380.8 cps时仍剩16‰，543203降为0；同阶段P阻尼与误差I正常纠偏，不能称控制器完全没有减力。

以上解释现有“晚到近停门槛、加入较整块恢复、再逐步退出”的命令机制。它不能证明只要改早触发就一定更平稳，也不能证明最初掉速是此门槛或硬件单方面造成。

### RF：这一段不是短时恢复反复开关

在所述假设下，三组回放的RF recovery始终为0；总FF变化可由load约27～60‰解释。RF先在仍运动欠速阶段恢复load，每20 ms最多约0.8‰，542583恢复到60‰上限。

随后RF加速：250 cps时普通超速P阻尼已生效；542783约307.7 cps首次超出`目标+max(20,目标×10%)`门槛，load超速计账20 ms；542803计40 ms；542823累计60 ms后开始撤load。三帧20 ms的计账是60 ms，首末时间戳相差40 ms，不混淆两者。

542823～542863回放load约57.75→55.08→52.11‰，I约5.9→5.2→4.3‰、P阻尼也同步减驱动，PWM133→127→121‰。故不是积分到上限、补力越叠越大或完全没有超速纠偏；现有确认/斜率和真实负载动态一起形成了较宽的速度波动。

LR近停与RF/RR加速在时间上重叠，符合需要检查四轮地面阻力/负载耦合的情形，但**相关不等于已经证明“LR停住导致RF超速”**。没有电机电流、独立轮速、接触力或严格控制变量对照，仍不能唯一归因。

## 设计建议（未实施）

不建议增加整车PWM上限、提高最低指令速度、放宽堵转保护，或同时改LR与RF来追求一次均速好看。

优先做**仅LR反向PIVOT、已确认运动后的掉速/恢复协调离线原型**：

- 研究有持续确认的移动欠速支撑，在滑到近零前有界介入，拒绝短时量化抖动；不是把20 cps门槛随意提高后立即施加整块60‰。
- 对已有I/残留bias和临时项统一计账、限制合成升降变化；近停恢复只用既有权限、一次有限尝试，运动/超速时可撤减，避免退出后仍有不必要的临时支撑。
- 不改LR首次起步、LF已验证候选逻辑、RF/RR、直行、编码器/滤波、USB、IMU和安全停车；先冻结隔离回归与边界，再决定是否合入候选。
- RF暂不同时调整，待LR变化后相同目标、方向、地面和供电下重新评估。若仍有波动，再独立审视RF超速确认与支撑卸载，而不是预先断言修LR会顺带消除RF问题。

这仍是下一步建议，没有新增原型策略或生产修改。任何实现/编译新候选及实车运动都需另行明确范围。
