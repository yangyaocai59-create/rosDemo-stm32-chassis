## 1. 结论先说

1. 记录中的四轮控制输出可以由冻结的实际 C 代码在规定计数反馈下解释，没有发现本次数据中的 PWM 异常写零、目标被偷偷改变或可复现的软件跨轮覆盖。
2. RR 的新补力预算、渐变及撤减确实能产生本次波形，但**输出更平缓不代表车轮更平稳**，实车停顿恢复问题仍在。
3. 值得继续优化的是恢复阶段：原始计数已明显加速，而控制只依赖较慢滤波反馈；此前的 A→I 转移保留总支撑，并非撤力。因此下一步更合理的是研究恢复阶段的提前退出与转移条件，而不是直接提高 PWM、Kp 或 Ki。
4. 这仍不能证明最初停止的唯一原因；真实负载、机械/电气与四轮耦合均未被此次离线工作排除。

## 3. 回放吻合程度与隐藏初态限制

ring 是事后状态，丢失启动及前段历史。首帧滤波、积分和前馈的小数只能由打印区间取种子，不把首帧当独立验证点；前轮假设初始 recovery=0、所有 FF 超额分配给 load，LF已经完成首次起转。LR假设已有运行所有权且A=0；这不唯一识别实际所有权。

RR假设已有运行所有权，初始 A=首帧FF−基础FF、active/spent为真，初始积分来自打印值。中间种子假设 episode已经200 ms、最后一次运动距首帧140 ms。

| 轮 | 首帧之后 PWM 完全一致 | cps/FF/P/I/PWM最大打印误差 |
| --- | ---: | --- |
| LF | 124/126 | 每项至多1个对应刻度 |
| LR | 122/126 | 每项至多1个对应刻度 |
| RF | 125/126 | 每项至多1个对应刻度 |
| RR | **126/126** | PWM/FF/P完全一致，速度至多1 cps、I至多0.1‰ |

低/中/高三组打印小数种子，所有轮每个字段误差都不超过1个对应打印刻度。PWM单位1‰，FF/P/I单位0.1‰，速度单位1 cps。

进一步筛选275组 RR 初始 episode/最后运动年龄组合：episode=120..600 ms步20、无运动年龄=0..200 ms步20。在中间量化种子下，有12组吻合：episode=120..340 ms、无运动年龄140 ms。因此不能从相同波形反推出唯一私有计时历史，更不能把中间种子当实测内部状态。

RR首帧已处于无计数间隔内；140 ms年龄与162602 ms时真实估计器强制归零相符，但不是直接读取私有 last_motion_ms。该筛选不是所有连续种子/历史的穷举。

## 4. 恢复阶段为何仍可能冲过目标

以下数值为匹配回放的中间种子，原打印记录有相应量化误差。A为推定的临时项，**不是UART直接上报字段**。

| MCU t ms | 原始速度 cps | 滤波速度 cps | 临时A ‰ | I ‰ | PWM ‰ |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 162642 | 0 | 0 | 48.650 | 11.350 | 169 |
| 162682 | 50 | 14.286 | 48.650 | 11.350 | 168 |
| 162722 | 250 | 99.125 | 48.650 | 11.350 | 164 |
| 162742 | 200 | 127.947 | 47.850 | 12.150 | 163 |
| 162762 | 350 | 191.391 | 47.050 | 12.950 | 159 |
| 162782 | 300 | 222.422 | 46.250 | 13.750 | 158 |
| 162802 | 400 | 273.158 | 38.250 | 13.587 | 144 |
| 162902 | 400 | 349.998 | 0 | 11.564 | 92 |

- 从162742开始，A每帧减0.8、I加0.8，属于原40‰/s转移，不是普通Ki积分重复增长。162642与162782的FF+I均约156.871‰（基础96.871+共享60）。
- PWM本身已从169逐渐减到158，主要因为P误差变小；**不能说这个阶段PWM仍在上升**。但额外支撑总量仍保留到滤波超速，转移本身没有起撤力作用。
- 162762原始350 cps时，滤波仍191；162782原始300时滤波222，控制仍认为未超目标。162802滤波273才满足RR超速条件，此后按400‰/s撤A。
- 中间种子下退出增力时episode为460 ms，不是600 ms超时。其他吻合episode种子也能产生此波形，其中340 ms种子可在同一帧达到超时；不宣称唯一退出原因。
- 加入误差裕量max(20 cps,目标10%)约24.064 cps：单次原始速度、40 ms计数窗最早162762显示超过目标+裕量；两个连续原始样本确认到162782；滤波首次过目标162802。可见本段20～40 ms观测差。

**上述早期检测时刻仅用于诊断，不是已经选定的新控制阈值。** 20 ms一个计数就是50 cps，40 ms窗一个计数25 cps，不能拿单次原始值直接替换全局反馈，否则可能引入量化抖动和错误撤力。更早撤力也可能让尚未稳定恢复的车轮再次停下，必须先做限定离线原型和安全验证。

## 5. 四轮联动能确定什么、不能确定什么

- RR可见无计数段从ring开头到162662；LF零增量162662..162942。两者只有一个20 ms记录间隔交叠，RR加速阶段LF仍无计数；RF的180 ms缺口在更后的164442..164602。LR本段没有零增量。
- 规定同一反馈时，把四轮更新顺序反过来，全部输出和CSV中诊断状态字段逐值一致。
- 单独扰动RR的规定计数输入，RR输出改变，但LF/LR/RF的全部CSV输出和诊断字段不变。这未显示这些固定输入下的直接跨轮覆盖。
- 控制目标持续稳定、计时20 ms、STBY为1，完整采集中无CRC/overflow/drop或健康故障，不支持把本段停顿归因为STOP、链路断开或失去调度。

这些不是完整并发/中断/驱动电路证明。真实车体上的受力、供电和运动学耦合没有被规定反馈模型模拟，不能用“代码隔离通过”排除物理耦合，也不能凭时序相邻判定哪只轮导致另一只轮欠速。

## 6. 建议的下一步范围（尚未执行）

先仅研究RR正向PIVOT的**恢复退出**，不同时改四轮：

1. 保留现有滤波用于普通PI/遥测；研究用短窗口计数、方向一致性和连续确认给临时恢复增加更快的退出判据，不直接使用单脉冲瞬时速度。
2. 区分“已有计数、正在明显加速”与“稳定欠速”：加速恢复阶段避免继续把临时补力转成稳态I，按有界速率撤减，而不是等滤波超目标才开始大幅退场。
3. 不增加PWM/I/共享权限、目标速度、重试次数，不改编码器采集、USB、IMU或其他轮，不放宽故障门槛；验证退出后再欠速、低目标量化、换向、所有立即停车路径及实际堵转计时。

先离线证明控制约束、原范围隔离和安全无退化，再单独申请集成/编译及实车对照。这个方向针对**恢复后的突然加速**，不是已经解决最初不转/摩擦停顿；若离线原型不能稳定兼顾两者，就应报告限制，不继续凭更大PWM反复试车。
