与[前一轮](../2026-10-23-v01824-ground-left/README.md)对比：上一轮首次窗口包含LF原始CNT440ms不变，本次换到RF340ms。可重复的是“某轮在加力下出现零净计数区间”，不是已经证明某个固定轮损坏、固定计数器采集bug或物理堵转。

当前两轮原始CNT与累计一致，配置检查均未异常；没有ROS换算丢数或硬件CNT推进却软件不取的证据。20ms GPIO采样仍不能证明窗口内没有边沿，瞬时CCR也不测量电机端电压/电流。需要独立轮动/输入脉冲证据，不能继续仅按编号叠补力或提高保护容忍度来宣布解决。
