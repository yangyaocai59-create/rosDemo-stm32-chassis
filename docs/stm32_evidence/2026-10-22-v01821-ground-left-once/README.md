# 0.18.21 单次落地左转：末段改善，但中段 RR 反馈间歇仍在

2026-10-22，Asia/Singapore。用户报告烧录完成，要求直接落地；随后确认落地、VM 开启、约 80 cm 空间、线缆/人员安全、ROS 和串口助手关闭，同意 **一次左转 0.30 rad/s、最长 6 秒，异常停止，不清故障重试**。

## 结论

动作完成 6 秒、120 条速度命令全部接受、无故障并确认四轮停稳；端口已关闭，没有重复运动。用户现场反馈：**“RR 连续，没有明显停顿或突然加速”。** 末段速度数据也比 .20 平稳。

但是整段 USB 数据显示 RR 在约第 3.16～3.31 秒出现 **140 ms 累计净计数保持 939 不变**，滤波速度从 83 降到 8 cps，随后恢复。此事件恰在最后 2.54 秒详细环形记录之前，**不能用末段没有零计数宣布问题解决**。本次仍不接受为重复性/完整跟踪通过，也不据此直接出下一版或继续试车。

“累计净计数未变”不是独立光学轮速，也不能证明精确物理停转时长；用户没有看见明显顿挫与遥测异常可以同时存在。当前只能确认仍有显著反馈欠速/恢复，不能断定编码器坏、驱动断输出、供电掉压或机械卡滞的唯一原因。
