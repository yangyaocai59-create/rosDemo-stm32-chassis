# 0.18.19 RR离线复核：旧恢复介入较晚、退出期间仍有支撑，不是PWM打满

日期：2026-10-22，Asia/Singapore。用户同意只离线复核RR补偿，**不连接串口、不运行车辆、不改生产固件**。本轮冻结源码、编译两个本机C回放EXE并分析既有记录；未进行Cortex固件构建/链接、清故障、校准、烧录或推送，当前候选仍是0.18.19。

输入为[刚才单次落地左转300](../2026-10-22-v01819-ground-left/README.md)：完成6秒且用户观察四轮连续，但末段RR有100ms及40ms两段零计数，速度反馈14～404 cps。以下解释**命令如何形成**，不是对最初机械/电气原因的确诊，也不是新策略会改善实车的预测。

## 1. 核对方法及可信边界

- 从当前.19交付清单冻结14个源码/头文件/原测试桩，原始哈希一致；生产149项及HEX/BIN/ELF/MAP四个产物在分析前后均不变。
- 使用实际C版chassis补偿、PI、运动学；输入已记录的RR/RF原始dc，按实际20ms周期、50ms低通及200ms无计数归零规则重建反馈。
- 环形trace只有末段127个ACTIVE帧，缺少起步/私有状态。第一帧作为后状态种子：打印截断区间中点加微小扰动，RR初始bias=0、曾运动为true；RF假定临时恢复=0、FF超出base的部分属于load。第一帧不计验证行。
- 测试中点/低端/高端三套量化种子，以及RR“此前无restart/此前restart已结束且bias为0”两个历史假设，共六种。它们是敏感性检查，不是所有隐状态的枚举。
- 六种下RR/RF后续126行的速度、FF/P/I、PWM打印差异均≤1打印单位（FF/P/I即0.1‰、PWM1‰、速度1cps）。中点RR PWM **126/126逐行完全相同**，其打印速度/FF/P也完全相同，I差异≤0.1‰；RF PWM122/126相同，其余最多1‰。

额外用冻结.18原C及其原测试桩运行同样六套输入/种子：**每套RR/RF全部回放CSV与.19逐字节相同**。证明在这些规定输入/假设下，两版保留的RR/RF命令生成一致；不能据此要求两版真实车辆的RR反馈也一致，因为LR变更、负载及初态会改变实际耦合响应。

首个零计数帧到加补偿相隔80ms（从最后非零帧算100ms）。六套种子的restart入口均1078642、释放均1078722，保持80ms；没有发生80ms后的额外10‰升级，因为到该次更新时已恢复到50 cps并先退出active。

**不是“补偿完全不撤”**：恢复后每帧减4‰，超速P阻尼和I回退也在作用；但暂时项退出依赖“速度≥50”且按固定斜率，首次超速并不令其立即归零。因此在超速过程中仍存在有限残留支撑，是需要协调的设计点，不等于仅凭相关性证明它造成了404 cps峰值。

## 3. I与暂时项并非全程连续共享预算

入口余量计算正确执行：60−12.408≈47.592‰。前两帧I不增加主要由原输出斜率抗饱和限制；输出追上后，后轮普通正误差积分继续，I约12.41→14.64‰，暂时项仍47.59‰，二者合计最高约**62.23‰**。

这不是突破300‰PWM硬上限，也不是I打满50‰后的释放。本段I峰值约16.74‰、实际PWM峰值170‰，都有余量。它说明旧后轮只在restart入口扣了既有I，并没有像.19新LR路径那样在整个恢复过程中持续协调临时项与同向I。这个约2.23‰的额外积分只是一个设计细节，不能夸大为全部超调的唯一原因。

## 4. 为什么不能说是USB断续或已经排除硬件

本段请求/应用均稳定+300 mrad/s，source dt20ms、STBY=1，CRC/overflow/drop为0。UART连续零dc与USB RR计数短暂保持一致，支持计数缺口不是单个打印显示错误；原始记录未显示主机STOP或命令中断导致最初缺口。

但20ms快照不能排除更短电气事件；编码器输入链路、机械阻力、滑移、瞬态供电/电流及轮间负载耦合都没有在本轮新增测量。只能说“有控制协调上的可改进点”，不能说“所有问题一定由固件造成”或“硬件肯定正常”。

RR缺口也**先于**恢复支撑，不能反过来把后来补力当作最初缺口的原因。低速小计数量化、真实短停或编码器信号问题的区分仍受证据限制。

## 5. RF辅助核对

六套假设下RF临时recovery保持0，记录可由已有load恢复/撤减、P和I重建到打印精度内；没有证据显示本段RF也在触发同一种rear restart。RR开始恢复时其他轮速度也改变，只能记录时序相关，不能据此证明因果方向或应把各轮同时改动。

## 6. 建议的下一步（未执行）

建议只研究**RR正转PIVOT、已确认运动后的运行恢复协调原型**，不调整RR反转、首次起步、普通直行或其他轮：

1. 研究在持续运行欠速阶段更早、渐进地介入，而非等滤波≤20后集中补力；只在旧支撑已安全退出后移交，避免叠加或突然撤掉现有支撑。
2. 连续协调暂时项和同向I的权限；运动恢复、负载减小或超速时及时撤减，避免恢复期间重复积分。不能仅把补力幅度/速度调大。
3. 采用有界单次窗口、不静止反复补力，保留当前PWM/I/输出斜率上限；不要直接照搬LR参数就认为有效。
4. 若后续获准做原型，**同时审计故障计时与四轮锁存关断**，沿用.19“不晚于旧保护”的验证要求，不能重犯LR v1撤补力后重置堵转计时的问题。
5. 先做冻结C隔离、无反馈/超速/模式退出及故障锁存回归，再决定是否值得合入候选和实车测试。本轮没有编写新控制原型或生成新固件。

不建议继续重复整套运动测试、直接加大PWM、统一抬高ROS转速或同时重调四轮增益。当前数据已足够先推进限定范围的离线原型研究；物理根因与整车长期验收仍未完成。
