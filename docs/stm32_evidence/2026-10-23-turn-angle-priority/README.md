# 验收重点调整：角度误差优先，容忍轻微顿挫

2026-10-23，Asia/Singapore。用户说明“只要编码器转向角度误差不大，顿挫无所谓”。因此停止把完全消除顿挫作为必须单独达到的目标，优先检查轮计转角与独立角度参考的差异、重复性及动作完成能力。未据此放宽故障保护、改写累计计数或追加运动。

## 已有记录的离线初筛

使用D=0.065m、1560count/rev和ROS先前给定有效轮距0.395m，不重新拟合几何。左右侧分别取前后轮累计增量平均：

`yaw_rad = ((dRF+dRR)-(dLF+dLR))/2 * (pi*D/1560) / 0.395`

IMU均bias_valid=false。对每次动作前800ms共80个唯一IMU样本取Z轴静止均值，梯形积分时扣除此临时基线；这只用于离线对照，没有校准板上、保存Flash、修改原始计数或ROS接口。去除完全相同的重复源样本，按MCU源时间积分，并检查间隔。窗口含动作与故障/停车后约1秒余动。

| 记录 | 编码器估计 | IMU临时基线参考 | 编码器减IMU |

限制：

- 这些是两种估计之间的差异，不是相对实际地面角度的真实误差。没有180°地面标记/独立计量结果，acceptance_pass保持null。
- 动作前基线只有0.8秒；用动作后5秒静止均值替换时，三次IMU积分参考分别变成128.03°、64.36°、125.93°，说明基线选择仍引入约0.2～0.9°变化。短时间静止噪声不代表传感器全误差界限。
- 每次保护附近有一次IMU源样本计数跳变2或3，最大源间隔20/30/20ms。以跨间隔梯形积分处理并明确记录，没有伪称没有丢样，也没有填造源样本。
- 两次0.18.24的动作时长、角度不同，不是同目标重复180°，不能由差值接近直接宣布180°重复性通过。
- 净计数使用整次静止前后状态，包括余动；与IMU积分末端附近的USB累计对照，0.18.24第一次RR相差1count，其余一致，该点也保留为窗口匹配限制。
- 不可用指令0.30rad/s乘时间当作实际转角真值；四轮滑移转向、有效轮距和实际轮速都会影响车身速度。

## 阶段建议

可以将“实际转约180°时编码器角度误差不超过10°”作为宽松的待确认阶段目标，并用左右转各几次检查是否稳定。10°是建议验收容差，非产品标准或本轮已经达成的实测结论。不要把每次测得的角度重新调轮距到恰好相等。

轻微顿挫如果不影响角度和完整动作，可以暂时接受；当前多次保护提前中断仍妨碍完成命令，不能因为只看角度就宣布整个ROS底盘已可交付。后续应围绕完整动作、角度差异与重复性补证，而不是无限追求速度曲线外观平滑。

分析脚本：`Tools/assess_existing_turn_yaw.py`，只读已有USB文件；`comparison.json`为结果。没有打开串口、清故障、重新运动或改固件。
