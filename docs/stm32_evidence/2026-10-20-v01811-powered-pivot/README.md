# 0.18.11 地面低速 pivot 实测，2026-10-20

结论：用户反馈“更连续、更均匀，没有异常”。前轮显式转向负载前馈的行为得到验证：LF 左转长零计数区间明显减少，右转 LF 末段均速恢复到目标附近；本窗四轮积分均未达到上限。但左转 RF/RR 最长零计数区间增大，左转 LF/LR 均速偏高，右转整体 RMS 基本不变。不能标记低速 pivot 全部通过，也不据此继续增加补偿或提高输出上限。

## 条件和证据范围

- 用户报告已烧录 [0.18.11-pivot-load-feedforward](../../STM32_PIVOT_LOAD_FEEDFORWARD_0.18.11_20261020.md)。未回读 Flash、未重新取得 Boot Banner；前轮 FF 与配置一致，不代替独立镜像身份验证。
- 运动前先只读确认 COM4/COM8、IDLE、四轮静止、fault=0/0，供电遥测约 10.725 V；用户确认四轮落地、约 80 cm 空间、线缆有余量、无人接触。
- vx=0、wz=+200/-200 mrad/s，各 6 秒，每方向 120 条速度指令。每次 STOP 确认停车，再保持串口连接读完 TRACE END。
- CH340 打开前 DTR=False、RTS=False；CDC DTR=True、RTS=False。没有主动复位。
- 左转供电遥测 10406..10725 mV，右转 10428..10736 mV。不是示波器纹波或瞬态电流测量，不是已校准的 12 V 电源。
- 对比 [0.18.10 同目标测试](../2026-10-20-v01810-powered-pivot/README.md)。摆放、摩擦、温度和接触负载未严格固定，单次差异不能全部归因于代码。
- 每方向 128 帧 trace：127 ACTIVE、1 STOP，四轮字段完整，源间隔恒定 20 ms。左 ACTIVE 197142..199662 ms，右 236202..238722 ms，分别只覆盖末段约 2.52 秒；全程另有 USB。以下 trace 统计不能称为完整 6 秒统计。

四轮 RMS 简单均值：左约 97.25→74.18 cps，右约 48.56→48.30 cps。右转不能表述为整体误差明显下降：改善集中在 LF，其余三轮 RMS 均上升。左转 LF/LR 末段均速幅值分别比目标高约 26%/21%，仍非均匀精确跟踪。

USB 2..6 秒平均 LF/LR/RF/RR：左 `[-165.97,-170.65,+164.25,+163.31] cps`，右 `[+148.26,+169.85,-156.49,-169.38] cps`。较长窗口均值与末段均值不同，不能因前者接近目标忽略内部波动。右转 motion 阶段 elapsed=0 有一帧发送首条速度前已收到的 IDLE，之后均 ACTIVE，无运动中退出 ACTIVE 的证据。

## 零计数区间

定义为 20 ms trace 的 dc==0；单帧不等于完全停转，长区间需结合滤波速度和 PWM。本次所列最长区间均不触及窗口两端，观察到后续恢复。

| 方向 | 轮子 | 旧零计数占比 | 新零计数占比 | 旧最长/ms | 新最长/ms |
| --- | --- | ---: | ---: | ---: | ---: |
| 左 | LF | 29.92% | 0.79% | 760 | 20 |
| 左 | LR | 22.05% | 8.66% | 480 | 200 |
| 左 | RF | 10.24% | 13.39% | 140 | 340 |
| 左 | RR | 20.47% | 17.32% | 200* | 380 |
| 右 | LF | 1.57% | 0% | 20 | 0 |
| 右 | LR | 0% | 0% | 0 | 0 |
| 右 | RF | 3.94% | 6.30% | 100 | 120 |
| 右 | RR | 7.87% | 10.24% | 120 | 140 |

*旧版 RR 左转 200 ms 区间在 STOP 窗口末尾被截断，未记录继续运动时何时恢复，不是完整停顿时长。其他比较也仅针对各自有限窗口，不是重复试验置信结论。

四轮平均零计数占比：左约 20.67%→10.04%，右约 3.35%→4.14%。总体改善与个别轮停顿变长可以同时成立。

左转重点事件：

- LF 仅 199382 ms 一帧 dc=0，滤波速度仍 -95 cps，下一帧 dc=-2；没有旧版 760 ms 长零区间。
- LR 199342..199522 ms 连续 200 ms 零计数，滤波速度 -83→0 cps，PWM -84→-153‰；199542 ms 恢复 dc=-6。
- RF 198862..199182 ms 连续 340 ms 零计数，滤波速度 +95→0 cps，PWM +120→+136‰；I 从 -21.5→-9.8‰，FF 始终 +138.2‰；199202 ms 恢复 dc=1。
- RR 198802..199162 ms 连续 380 ms 零计数，滤波速度 +57→0 cps，PWM +99→+174‰；199182 ms 恢复 dc=1。

RF/RR 零区间重叠，需继续区分四轮地面负载耦合与控制支撑；不是已证明机械卡滞、电流不足或编码器漏计数。RF 均速虽接近目标，仍有停顿与较高速阶段交替。

## 前馈和积分

前轮满量目标的 FF 重构，单位均为 PWM 千分比，不是最终占空比百分数：

| 轮子/方向 | 原架空 FF | 显式 load | 基础合计 | 本窗观测 |
| --- | ---: | ---: | ---: | --- |
| LF 左转/后退 | -69.8 | -65 | -134.8 | 恒定 -134.8 |
| LF 右转/前进 | +75.2 | +60 | +135.2 | 恒定 +135.2 |
| RF 左转/前进 | +78.2 | +60 | +138.2 | 恒定 +138.2 |
| RF 右转/后退 | -79.6 | -45 | -124.6 | -124.6..-139.6，含至多 15 短时预算 |

未见 load 再叠加完整 60‰ 旧 kick。前三种方向短时预算为零，FF 不反复跳变；RF 后退仍有剩余 15‰，不能称所有前轮 FF 恒定。

四轮积分本窗均未到 ±50‰ 上限。左 LF/LR/RF/RR 范围 `[-41.4,-11.3] / [-30.2,-2.8] / [-22.1,-8.0] / [+4.6,+22.5]‰`；右分别 `[+9.1,+19.9] / [+20.5,+37.0] / [-13.4,-4.9] / [-6.7,+0.4]‰`。旧版右转 LF 持续 +50‰ 上限不再出现。

这支持分离运行负载与启动瞬态的设计，不证明参数已最优。总 PWM 仍包含 PI 和斜率约束，不能从 FF 列单独判断电机力矩。后轮软件没直接修改，不代表整车耦合下后轮表现一定不变。

## 通信、实时性和停车

- 240 条速度指令全部接受，拒绝 0，fault=0/0。
- 主机 CRC=0，固件 CRC/RX overflow/TX drop=0。
- motor_dt=20..20 ms、safety_dt=10..10 ms，overrun=0/0、log_drop=0；本记录未出现新 Boot Banner/Reset cause。
- 每次及最终 STOP 确认 IDLE/EXPLICIT、请求及四轮速度为 0。最终 STATUS t=272445 ms，flags=0x0150。
- 未重做物理拔线、急停或掉电试验。IMU bias=0，本次未自动校准，也未验收角度；交 ROS 前仍需显式校准保存。
