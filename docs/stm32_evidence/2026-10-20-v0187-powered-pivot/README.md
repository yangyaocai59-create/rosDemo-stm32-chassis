# 0.18.7 有电池地面 pivot 对照，2026-10-20

结果：用户反馈“更平稳，速度也更均匀”，末段整体轮速误差与零计数占比下降。但 RR 左转超调增加、LR 左转仍明显超调，因此不能宣称后轮跟踪或底盘控制全部通过。

## 测试条件与身份

- 用户报告已烧录 [0.18.7 镜像](../../STM32_PIVOT_DAMPING_0.18.7_20261020.md)。本轮未回读 Flash，也未重新捕获 Boot Banner；以用户烧录报告和 trace 中吻合新 P 项的行为作为身份依据。
- 沿用用户已确认的落地、约 80 cm 空间和供电条件。只读检查 COM4/COM8 正常、IDLE、四轮静止、fault=0/0 后执行。
- 左右各一次，`vx=0`、`wz=+200/-200 mrad/s`，每方向 6 秒、120 条速度指令。每方向停止并读完 `TRACE END` 后才继续。
- 每方向取得 128 帧：127 帧 ACTIVE、1 帧停车；ACTIVE 覆盖末段 2.52 秒，20 ms 间隔，无缺帧。
- 左转供电遥测 `10428…10758 mV`，右转 `10406…10648 mV`。电池/负载电压不是完全受控恒定量，不能视为严格实验室对照。
- 未修改、编译或烧录新固件来取得本轮数据；采集期间没有再次驱动车辆补测。

## 控制行为与未解决问题

内部 trace 中请求/应用角速度恒定为 ±200 mrad/s、目标恒定为 ±160 cps。P 项在同向超速时与 KP=0.15 一致，欠速时与 KP=0.05 一致。FF/I 交接仍在工作，前馈减小时 FF+I 的最大相邻变化约不超过 1.5‰，没有回到旧版退出时一次撤走 60‰。

重复启动补偿投入时，FF+I 仍能增加最多 60‰。RR 左转平均 PWM 约 115.63‰，高于 0.18.6 的 106.64‰；其平均积分支撑也增加。因此，单独增大超速 P 并未使后轮同时收敛，需要进一步检查补偿再次投入、积分支撑与带载摩擦/四轮耦合的时间关系，不能继续只按全局 P 倍增推断改进。

右后轮此前 [架空点动和 ±500 cps 检查](../2026-10-20-v0185-rear-check/README.md)均能连续跟踪；本轮结果也不能直接推出电机或编码器损坏。尚不能完全排除仅带载出现的机械差异。

## 通信与停车

- 240 条速度指令最终全部接受，拒绝数 0。
- fault=0/0；主机 CRC=0；固件 CRC/RX overflow/TX drop=0。
- 两次显式 STOP 后均确认四轮速度为 0。
- 最终 IDLE/EXPLICIT，请求速度和四轮速度为 0，flags=0x0150。
- 本轮没有重新执行物理拔线、急停或掉电测试，不将之前的离线回归当作本轮实板测试。
- IMU 在全片擦除后 bias=0；本轮没有校准或用其验收车体角度，交 ROS 使用前仍需按原流程校准保存。
