# 0.18.6 有电池地面低速 pivot 对照，2026-10-20

结论：补偿退出交接行为得到实板数据支持；停转占比下降，用户反馈“明显更连续，顿挫减轻”。但部分轮子平均速度偏高、仍有瞬时起停和速度波动，低速轮速跟踪精度不能标记通过。本轮只进行两个方向各一次的对照，不能推断长期稳定性。

## 身份与条件

- 用户确认已烧录本次提供的 `0.18.6-pivot-bumpless-handoff` 镜像，随后确认四轮落地、有约 80 cm 空间且可以测试。
- 本轮未重新捕获启动 Banner，也未回读 Flash；版本身份依据用户烧录报告及 trace 中吻合新实现的 FF/I 交接行为。镜像校验值见 [交付说明](../../STM32_PIVOT_HANDOFF_0.18.6_20261020.md)。
- COM4=STM32 USB CDC，COM8=CH340；CH340 打开前设置 DTR/RTS=false，期间保持连接。
- 左转 `vx=0,wz=+200 mrad/s`，右转 `vx=0,wz=-200 mrad/s`，各 6 秒；每方向发送 120 条指令，共 240 条。
- 每方向停车后确认轮速为 0，读取到 `TRACE END` 才开始下一方向。每方向 128 帧：127 帧 ACTIVE、1 帧停车；运动 trace 覆盖末段 2.52 秒，20 ms 间隔，无缺帧。
- 左转供电遥测 `10417…10780 mV`；右转 `10428…10780 mV`，与前一版基线的 `10406…10780 mV` 接近。它不是同步万用表或电流波形。
- 请求/应用角速度在 ACTIVE trace 内保持 ±200 mrad/s，四轮目标为 ±160 cps。

## 补偿交接是否生效

在目标恒定、前馈绝对值下降的相邻记录中，检查 `FF + I` 的变化：

- 0.18.5：最大约 60‰。
- 0.18.6：各轮最大不超过 1.5‰（包括正常 PI 误差积分与日志量化）；观测到前馈下降、积分接管或保留剩余前馈。

这支持“退出时撤力阶跃已被消除”的局部修复结论。重新投入补偿仍可使 FF+I 增加最多 60‰，输出仍由既有斜率限制；不能将前馈值每次变化都当作原来的两档抖动，因为新版前馈现在也会连续小幅变化。

积分触限情况：LF 左转约 35/127 帧、LF 右转约 109/127 帧、RF 右转约 27/127 帧达到 ±49.9‰ 附近；总 PWM 未到 ±300‰。这与旧版末段积分未触限的情况不同，应作为后续调节依据，而非忽略。

## 通信与停车

- 240 条速度指令全部接受，拒绝数为 0。
- 主机 CRC=0；固件 CRC/RX overflow/TX drop=0；fault=0/0。
- 本轮运行内没有中途 STOP/FAULT 帧；每次显式 STOP 后均确认四轮速度为零。
- 最终状态 `IDLE/EXPLICIT`，请求速度为零，四轮速度为零，flags=0x0150。
- 本轮未额外执行真实拔线、急停或掉电测试；其离线回归结果不能当作本轮实板验收结果。
- IMU 在全片擦除后显示 bias=0；本次没有执行 IMU 校准，也未使用其角速度验收车体转角。交回 ROS 使用前仍需按原流程显式校准保存。

- `ch340.log`：本轮原始 UART 文本。
- `usb_motion_frames.jsonl`：从完整 USB 抓包筛出的原始 ACK/STATUS/WHEEL/BATTERY payload，保留主机 phase/时间与序列号；不包含本次无关的 IMU 帧。
- `trace_parsed.json`、`analysis.json`：解析后的 trace 和统计。
- `baseline_v0185_trace.json`：前一版同条件 trace。
- `baseline_comparison.json`：新旧比较。
- `summary.json`：采集流程与停止状态；`COMPLETE_NOT_A_TRACKING_PASS` 表示采集完整，不是轮速控制已通过。

完整本地 USB 抓包和解码位于 `build/hardware_tests/loaded_pivot_compare_20261020_134329/`；基线位于 `build/hardware_tests/loaded_pivot_compare_20261020_132405/`。

UART 主机阶段标记可能写入一段尚未结束的串口文本行。分析时按行内 `HOST_PHASE` 搜索，而非要求标记在行首；修正主机解析后两个方向均取得 128 帧。该解析修正未改变固件或原始日志，也没有因解析问题重复运行车辆。

建议下一步集中收敛低速超调和左右负载差异，以近零区间、RMS 误差、峰值和积分/补偿变化共同验收。保留当前 0.18.6 实测为部分改善基线，不直接交给 ROS 侧标记为底盘控制最终通过。
