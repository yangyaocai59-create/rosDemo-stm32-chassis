# 0.18.11 右前轮地面左转针对性复核

日期：2026-10-20（Asia/Tokyo）。保持 0.18.11，不修改生产固件。结果：两次相同 +350 mrad/s、6 秒左转中，第一次再次出现 RF 连续 500 ms 零计数，第二次 RF 连续，但 LR 有 140 ms 零计数。第一次 UART 原始计数与 USB 累计计数同时不变，不能归为单纯滤波或上位机解码现象。用户没有看清 RF 实际转动，因此仍不能确认是物理停轮还是编码器信号中断；下一步需要独立观察，不继续盲目增加输出。

## 范围、安全与记录

- 用户确认车辆落地、供电开启、周围空间充足、线缆能随车转动且无人触碰，同意两次同方向左转。
- 先只读 4 秒 GET_STATUS：IDLE、轮速 0、fault=0/0、flags=0x0150、供电约 10725 mV、主机 CRC=0。只读阶段未发 STOP、速度或调试命令。
- 沿用用户此前烧录的 `0.18.11-pivot-load-feedforward`；本轮未回读 Flash 或取得新 Boot Banner，不把控制行为等同二进制身份校验。
- 两次均 vx=0、wz=+350 mrad/s、6 秒、20 Hz/120 条。每次先 STOP 确认停车，再读完 TRACE END；无其他运动。
- 串口 COM4 CDC、COM8 CH340；CH340 open 前 DTR=False、RTS=False，中途保持连接，无主动复位。
- LEFT1 供电遥测 10384..10725 mV，LEFT2 为 10395..10615 mV。不是电流或高速波形测量，不能据此排除瞬态限流/压降。
- 每方向完整 128 帧 trace：127 ACTIVE、1 STOP，源间隔 20 ms，四轮数据完整。LEFT1 ACTIVE 1042362..1044882 ms，LEFT2 为 1081482..1084002 ms；只覆盖每次末段约 2.52 秒，另有全程 USB。
- 两次车体朝向、轮地接触及起步历史不同；这不是固定载荷的实验室重复，也不是两个固件版本 A/B。

## 当前可判断与不可判断

可判断：

- 现象在同固件重复出现，且不局限于速度滤波或 ROS 解码。
- 不是本记录中的 STOP、断链、任务周期超时或指令目标归零造成：ACTIVE 持续，requested/applied 不变、错误为零。
- 固定转向前馈不能保证所有接触条件下都连续，现有恢复机制值得优化，但还没取得足以唯一归因的证据。

不能判断：

- 用户反馈“没看清，无法确认”，没有同步视频、示波器或独立轴转速，因此不能把“编码器无脉冲”直接认定为物理停轮，也不能宣称已排除编码器/连接/供电信号异常。
- 没有电流或电机端电压波形，不能证明限流、驱动损坏或传动卡滞；PWM 是软件命令，不是实测力矩。
- 第二次 RF 正常不意味着不存在问题，第二次 LR 的短零区间也需纳入负载耦合判断。

下一步建议先以同固件进行一次同步视频与日志观察，安全距离对准右前轮，区分物理停轮与反馈中断。若轮子确实停，再核对机械接触、带载供电和有上限的重启补偿；若仍转而计数消失，优先核对编码器供电、AB 信号、连接与计数器链路，不应继续加驱动力。需要用户准备独立观察后再进行，不自动追加运动或生成固件。
