# 固定全片擦除的烧录流程

用户已明确：每次烧录必须全片擦除，无法改成按需或扇区擦除。后续按这个约束处理，不再要求保留校准扇区，也不将跨全片擦除保留校准作为验收条件。

当前 IMU 校准保存在 STM32 内部 Flash 的 `0x080C0000–0x080FFFFF`。普通断电可保留，全片擦除会清除。现有 0.20.5 不会在空白 Flash 中自动恢复曾被擦除的校准，也没有内置当前设备的历史零偏常量。

每次升级流程：

1. 用户按现有方式全片擦除并烧录指定的新版本；当前 0.20.5 已由用户烧录并完成后续校准。
2. 车辆保持静止，先只读检查 IMU 身份、初始化、有效采样和配置诊断。没有校准记录时，IMU 仍应可以初始化并输出未校准数据；记录缺失不能直接解释当前 IO_FAULT。
3. IMU 恢复有效数据后，通过现有显式校准接口完成一次静止校准，确认质量检查通过、精确零偏已应用以及 Flash 保存成功。保持现有运动互锁，不在 IO_FAULT 时发起校准。
4. 核对转向外环 RAM 基线就绪后，执行有界短时运动和停车验证。需要验证持久化时只做普通断电重上电，不再擦除或重刷，然后确认校准恢复。

主机侧执行校准不会依赖修改烧录工具。当前接口会保存新测得的参数；每次后续全片擦除后仍需重新校准。历史日志中有旧校准记录，但不能因此无条件写回某次旧温度、旧时刻的零偏。

本流程不改变固件代码、Flash 数据格式或任何已归档版本。全片擦除后的校准缺失与 0.20.4 中未发布首个样本的 IO_FAULT 分别检查；0.20.5 上板后有效采样已恢复，用户随后普通断电重上电，未重新校准即观察到已应用偏置与原校准温度，双向 180° 正常完成。见 [断电恢复与双向 180° 记录](stm32_evidence/2026-10-25-v0205-reboot-180-bidirectional/README.md)。
