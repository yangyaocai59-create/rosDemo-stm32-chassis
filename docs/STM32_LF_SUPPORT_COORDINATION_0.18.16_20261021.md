## 控制规则

LF仍只在PIVOT、目标幅值≥20 cps时使用这一策略，原误差带为max(20 cps,目标的10%)。

1. 持续超速达到原60 ms确认后，负载项撤减速率为 `clamp((超速超过误差带的cps) ×1.0,20,200)` ‰/s。比原固定200‰/s更渐进，但真正持续超速仍能完全撤回，没有新增不可撤回底座。P、普通I负误差修正和临时项退场仍立即响应。
2. 临时项优先使用400‰/s合成撤减预算，负载只能用余额；避免临时项400加负载200同时独立撤减。正向I的额外撤减仍和负载共用其预算，原反向I债务交接保留。
3. 已确认同方向运动（原≥50 cps、40 ms），明显欠速、恢复阶段退出且临时项为零、I非反向时，允许按 `min((欠速超过误差带的cps) ×1.0,40)` ‰/s恢复负载到原上限。**这是有界增加支撑，不是I的保守重分类**；发生恢复的同次普通正向I被冻结，不双加力。
4. 近零确认后的原负载恢复200‰/s与临时项自身上升250‰/s保持各自限制，但两项合计上升≤250‰/s，先负载后临时项。典型20 ms步骤由原最多+9‰变为最多+5‰。
5. .15已经起作用的运动欠速交接、原共享额度、300 ms恢复阶段/有限退场、1500 ms连续近零失败、模式/方向/停车清空均保留。

合成预算只针对固定目标/模式内负载+临时项的策略变化，不含P、普通误差I、模式/目标/符号切换及原反向I清零等变化。最终PWM仍受原幅值300‰及1000‰/s变化率限制；不能把策略预算误称为所有PWM变化上限。

## 保留的安全和局限

- I幅值50‰、有向I+临时项≤50‰、临时项目标缩放、各轮方向负载上限及原PI增益不变。
- STOP/零速/断链/健康故障/急停/250 ms命令超时/时序故障/超速原八条关断路径保留，包括补力转交中立即清空两种支撑。
- 持续近零恢复失败仍沿原锁存和四轮关断流程，不自动清故障重试；不缩短门槛掩盖欠速。
- 较慢撤负载可能延长卸载超调；较缓合成增力可能降低某些起步/恢复能力。运动中恢复仍可能在反馈延迟下过冲。峰值上限不变不代表每帧输出都比旧版小。
- 轮胎阻力、机械负载、电机端电压/电流瞬变、编码器硬件因素尚未排除。离线规定反馈无法预测真实停轮时长或RMS改善。

## 原定用户验证流程（已执行部分以上述分阶段证据为准）

1. 关闭电机VM，由用户手动烧录本版HEX；无需修改/重新生成CubeMX。
2. 维持“每次烧录全片擦除”的既定条件；这会清掉IMU偏置，本轮不自动校准。后续ROS交付前按原流程显式校准，不能把bias无效当本次轮速修改的新问题。
3. 告知烧录完成后先只读检查。若未捕获版本横幅，不通过STATUS伪认证版本；记录用户报告与证据边界，不为取版本而擅自复位。
4. 重新确认架空/电源/线缆/手远离等安全条件后，先低速左右架空。再另行确认落地条件，做一次200 mrad/s、最长6秒右转，重点LF，同时记录RF是否保持改善。
5. 故障立即结束，不自动清故障或重试；比较原始计数、滤波速度、FF/P/I/PWM、连续近零和恢复峰值及任务计时。即使用户感觉流畅，也检查欠速和零计数数据，不以“无故障”判整车通过。

历史原型`run_tests.py`会主动检查生产仍是.15，所以合入后不应在当前工作区强行绕过其保护来重跑。当前候选使用`Tools/tests/run_motion_tests.ps1`和新增隔离测试；历史原型结果保留为当时快照。
