**四轮控制优化方案（代码审阅版，2026-10-24）**

本方案基于当前工作区，HEAD 为 `a68b395`，固件标识为 `0.19.1-effective-track-candidate`。本次阅读生产控制代码、相关调度/驱动/安全/通信代码、现有测试入口及最近实车交接记录，并重跑离线回归。未修改生产代码，未编译新的 ARM 固件，未连接串口、烧录或执行运动。

**判断与范围**

可以继续优化，主要收益来自控制行为一致性、低速反馈、前馈标定、饱和处理和可验证性。当前已经是四轮独立 FF+PI，并且 0.19.0 已移除大量历史单轮恢复逻辑，不宜把已经完成的简化再次列为新增工作。

审阅范围覆盖 `Application/Chassis`、`Application/Safety`、电池测量与补偿接口、USB 速度/停车处理、运动诊断和 `Core/Src/freertos.c` 中相关任务。CubeMX 的编码器/PWM 配置作为硬件约束核对。ROS 部署代码不在本仓库内，方案只定义需要核对的接口。

现有优点应保留：四轮独立闭环、同侧一致目标、正反向独立前馈、按比例缩放轮速以保留曲率、实际输出回读、换向先归零、停车代次保护、直接急停关断、原始编码器累计计数及离线测试能力。

**当前实现和具体问题**

| 位置 | 代码事实 | 优化意义 |
| --- | --- | --- |
| `wheel_speed_controller.c`、`unified_pivot_control.h` | NORMAL 和 PIVOT 仍是两条 PI 路径；离开 PIVOT 清积分，进入 PIVOT 也有重新初始化语义 | 需要统一计算核心并处理无扰切换；输出斜率限制只能减缓跳变，不能消除内部不连续 |
| `chassis_controller.c` | 原地转向条件为线速度绝对值 ≤0.001m/s、角速度绝对值 ≥0.010rad/s | 阈值附近的微小命令变化会切换控制和保护路径，需要迟滞或连续工况权重 |
| `wheel_speed_control_config.h` | LF 转向附加前馈正/反向为 60/65‰，RF 正向 60‰，积分范围 ±50‰ | 积分无法独立完整撤回这些附加项；这属于调节余量问题，不能据此直接断言某次实车超调根因 |
| `wheel_speed_estimator.c`、`chassis_config.h` | 20ms 差分测速，低通时间常数 50ms，200ms 无净增量强制归零 | 反馈平滑但有延迟，低速还存在计数稀疏；实际停顿和输入异常需独立区分 |
| `wheel_speed_control_config.h` | 目标上限 1600cps，控制 PWM 上限 300‰ | 允许目标不等于可实现目标；RR 正向基础 FF 在 1600cps 已约 311.36‰，尚未叠加 PI |
| `chassis_motion_profile.c` | 对车体线/角速度分别限制加减速，没有 jerk 限制 | 混合运动时左右轮加速度是两轴组合；需要轮级可实现性约束，减少起停和曲率变化时的冲击 |
| `motor_driver.c` | 换向保护门槛 2ms，后续命令由下一控制周期重试 | 保护有价值，但实际等待通常由 20ms 调用周期决定；后续可在保持最短保护时间的前提下优化调度 |
| `chassis_controller.c` | 轮速接口检查 valid，未检查样本年龄和序号 | 当前主循环先采样再控制，通常保持新鲜；仍应在接口层明确过期和重复反馈的处理规则 |
| `fault_manager.c` | NORMAL 欠速保护要求目标 ≥200cps 且输出 ≥100‰；PIVOT 使用另一保护器，低于20cps不计时 | 两种工况覆盖范围不同，需补充低速失联/反馈异常策略，并检查模式切换是否重置保护历史 |
| `control_timing.c`、`motion_trace.c` | 已有周期/超期统计和同步 trace；trace 深度128、间隔20ms | 继续补充执行耗时、临界区时长和全程质量摘要；现有约2.56秒环形窗口无法证明整段长测试的每个样本 |

测速量化示例：1560counts/rev、轮径65mm时，每个计数约0.131mm；20ms窗口中的一个计数对应50cps，约6.54mm/s。若周期直接改为10ms，单计数对应100cps，因此提升频率必须连同估计器一起验证。

最近交接记录支持 ±0.40rad/s、约15秒连续执行，末段 trace 未见零净增量或积分饱和；同时轮式角度与 IMU 参考仍差约9–10%。没有外部角度真值，不能把这个差异直接归因于控制器、有效轮距或 IMU 中任一项。

**建议的目标结构**

```text
USB速度命令与序号
        ↓
Runtime状态机、命令时效与运动代次
        ↓
车体运动整形 → 差速分配 → 左右轮共同可实现性约束
        ↓
四个独立 WheelController 实例（共用一个纯计算核心）
        ↓
四轮输出准备 → 代次/急停复核 → 驱动提交 → 实际输出反馈

编码器同步采样 → 带时间戳和质量的速度估计 → 闭环与健康观察
安全链路可直接撤销驱动；诊断消费已发布的周期快照。
```

同侧前后轮使用相同速度目标，各自保留独立反馈、积分和硬件输出。统一核心允许按轮、方向、工况配置不同参数与输出策略，不强行把全部轮子的物理参数设成相同。

**P0：建立可靠的比较和反馈边界**

1. 固定现有版本、参数与现有实测记录，保存源码和产物身份。先建立每轮轮速误差、超调、稳定时间、零增量时长、饱和时长、停车延迟与任务耗时的比较报告。
2. 把采样时间、采样序号、采样间隔、原始增量、原始/控制轮速、有效性和异常原因封装成一致的周期输入。编码器采样时刻与控制周期统一取时，避免同一周期各层使用不同的毫秒边界。
3. 检查过期样本、重复消费、异常间隔及不合理计数跳变。明确无新反馈时如何撤销输出并锁存故障；保护模块不能把重复的旧样本当作新恢复证据。
4. 保留原始累计计数语义。出现平台时结合 sampled/live CNT、配置诊断与独立轮动/波形证据定位，不能让估计器生成虚假的运动计数。

**P1：统一控制核心与工况切换**

1. 将 NORMAL/PIVOT 的共同逻辑收敛为一个纯计算步骤：前馈、P、I、输出约束、斜率约束、抗积分饱和和结果发布。控制器状态改为每轮一个明确结构，减少平行数组和模式间隐含状态。
2. 先用兼容参数/输出策略保持现有两种模式行为，运行差分验证；再独立提交切换策略优化。后续行为优化使用指标验收，不要求与旧缺陷逐步相同。
3. 工况识别加入迟滞或连续权重。工况参数变化时，用实际已施加输出、当前 FF 和 P 计算积分跟踪值，并在积分能力不足时平滑过渡。防止直接清积分引起驱动力变化。
4. 抗饱和以实际施加输出为依据，覆盖 PWM 限幅、斜率限幅和换向保护。对条件积分与回算方式进行回放比较后选定实现。
5. 明确正目标下允许的输出策略。当前 PIVOT 把方向归一化输出下限设为0，而 NORMAL 可以给出反向输出；统一核心时必须显式保留/定义滑行和制动策略，并验证换向电气行为。
6. 参数改为按轮、方向组织的表，给出单位、来源、有效速度范围、标定版本。保留必要兼容接口，清理确认无调用的生产接口；历史证据不参与生产编译。

**P1：重做前馈和可实现速度范围**

借鉴 WPILib/SysId 的方法，拟合电压域模型：

`Uff = kS × sign(v_ref) + kV × v_ref + kA × a_ref + Uload(v_ref, w_ref)`

其中单位固定并写入参数定义。先标定 kS/kV，只有数据表明需要时加入 kA；转向负载项由带载数据决定，不能把简单电机模型当作完整轮胎滑移模型。

- 四轮正反方向分别标定，覆盖低/中速、不同电压、架空与带载工况；扫描区分启动摩擦与持续运动需求。
- 当前 FF 源自架空扫描，且12V只是假设，不能直接把现有系数视为已经标定的电压参数。
- 电压域 FF/PI 合成后，通过 `PWM‰ = 1000 × Ucmd / Vbus` 转为占空比，仍受现有300‰上限及换向策略约束。电压补偿需校验测量有效性、年龄、合理范围和变化速率，并制定异常时的退化/停车策略。
- 电池现有100ms采样、1/8低通，可供慢变化电压补偿评估，不能直接声称能实时补偿瞬时压降。
- 固定前轮补偿逐步替换为经过验证的连续负载项；积分保留对负载变化的调节余量，避免新增按单轮/阶段触发的临时补力分支。
- 根据每轮、方向、电压和输出上限确定可实现速度范围。任一轮能力不足时，在运动分配层统一缩放左右目标并报告限制原因，维持曲率；避免四轮分别截断改变运动轨迹。

**P2：测速、采样与运动整形**

- 首先在20ms基线上比较较小滤波时间常数、短窗/长窗组合及低速自适应窗口。控制反馈和遥测展示可采用不同平滑程度，但都必须保留真实原始量与时间戳。
- 低速根据实际计数间隔调整有效窗口和置信度，明确长时间无计数时的归零规则；停止判断、测量有效性和故障判断分别表达。
- 若增加脉冲周期测量，需先确认当前引脚/定时器是否有可用捕获路径及中断预算，不能假定现有硬件已经提供逐边沿时间戳。
- 评估10ms采样/控制作为第二个候选，必要时分离采集、控制、遥测频率。验收依据包括噪声、反馈延迟、计算余量和低速表现，不预先固定“越快越好”。
- 运动整形增加左右轮速度/加速度约束，并按需要加入 jerk 限制；车体线/角速度和轮级限制采用共同缩放/联动计算，避免多层独立限幅相互抵消。
- 零速速度命令、显式 STOP、通信丢失和急停沿用当前停车契约；本轮平滑整形不改变其直接关断语义。

**P2：驱动、并发与运行成本**

- 加入 DWT 或等效微秒计时，测量电机循环、测速、PI、输出提交、trace 以及 BASEPRI/PRIMASK 临界区时长。保留现有周期和漏周期计数。
- 在私有状态副本上计算四轮候选结果，提交时短临界区内检查运动代次、命令代次和急停，再发布状态和输出。任务级 Stop/Reset 与高优先级急停的交错必须通过测试，不能仅删除现有锁。
- 四路 PWM 同属 TIM8，可评估批量准备/提交与预装载更新的一致性；具体实现需检查方向 GPIO 与 CCR 的硬件生效顺序，不能用不受控的更新事件改变 PWM 时序。
- PWM比例换算目前包含临界区内的64位计算。若测量表明确有收益，再把可预计算的比例/比较值移出关中断区；同时验证整数范围和舍入。
- 换向等待与控制周期分离只作为测量后的优化项。保留2ms最短保护语义及最新命令覆盖，任何延期队列都不得在 Stop 后再次施加旧输出。
- 从控制周期直接生成统一诊断快照，减少 trace 再次跨模块复制。核心采样可降字段/分级保存，详尽故障环独立保留，UART 导出继续放在低优先级任务。
- 诊断与故障注入采用清晰的构建配置，检查 Release 的入口和资源；RAM/Flash 优化以实际 map 和栈水位为依据。

**P2：保护覆盖与通信契约**

- 健康观察使用同一个带代次、模式、样本时间的控制快照，避免分别读取 runtime/controller/PI 模式时混合不同周期状态。
- 明确反馈失效、严重欠速、反向运动、输出受限及普通跟踪偏差的区别。控制器报告测量与实际输出，安全模块拥有故障时间和锁存。
- 补齐普通低速工况的覆盖策略，并检查模式/方向反复变化是否反复刷新宽限期。现有正常/转向保护时间作为比较基线，不以放宽时限作为性能改进。
- USB 处理只提交最新速度意图与安全事件，电机任务拥有正常控制状态；保留 Stop 的立即撤销能力和运动代次失效机制。
- 新增诊断字段采用协议版本或独立消息，保留现有轮序 LF/LR/RF/RR、计数单位、速度单位和 ACK/STOP 契约。运行期参数更新必须原子校验并带版本；持久化参数使用独立布局和 CRC，不能覆盖 IMU 保存区。

**P3：协同与转角精度，作为有条件的后续项**

1. 先测量同侧前后轮误差、持续差速与 PWM 分布。只有独立闭环仍有明确同步问题时，再评估有上限、低增益的同侧同步修正；任一编码器异常时撤销修正，避免坏反馈拖动另一轮。
2. 保留当前395mm作为现有有效模型基线，使用独立外部角度/距离基准做双向、多速度重复试验。分别识别轮径、左右差异和滑移有效轮距，并核对ROS端唯一换算链路。
3. 外部基准确认 IMU 的符号、安装轴和动态比例后，再评估可选低带宽角速度外环。外环需有新鲜度检查、幅值限制和降级路径，并与ROS融合/控制明确分工。
4. 不提前引入 D 项、复杂观测器或在线自适应轮距。它们只在简单模型和实测证明有必要时进入独立实验。

**实施批次和验收**

| 批次 | 交付物 | 进入下一批次的条件 |
| --- | --- | --- |
| A：观测与输入契约 | 周期快照、样本新鲜度、微秒性能统计、比较脚本 | 原行为回归通过，诊断开关不影响控制，能分辨指令/计数/输出事件 |
| B：核心统一 | 公共单轮核心、显式输出策略、参数表、兼容接口 | 兼容配置差分通过；模式切换、过零、换向和Stop交错测试通过 |
| C：反馈与整形 | 测速候选、周期候选、轮级限制、平滑工况切换 | 模拟/回放无新增失控；实测低速噪声、响应和跟踪指标改善 |
| D：参数标定 | 四轮双向前馈、PI、有效速度包络、电压补偿 | 架空/带载及不同电压均通过，积分与PWM余量满足目标范围 |
| E：整车精度 | 外部基准报告、几何参数结论、必要时协同/角速度外环 | 直线/弧线/原地转向重复通过，ROS接口与角度精度验收明确 |

测试需覆盖真实生产控制核心和驱动/安全边界，不只测试公式。包括长时间恒速、命令抖动、低速稀疏计数、反馈冻结/跳变、模式阈值往返、原地转向转弧线、正反过零、掉压、PWM饱和、换向归零、Stop/断链/急停与提交交错、时钟回绕。提供同一输入的回放比较和含负载/死区/摩擦的简化仿真，明确其不能替代实车。

每次实车对比保存命令、时间戳、原始计数、轮速、FF/P/I、请求/实际PWM、电压、限制原因和故障事件。至少报告每轮稳态误差/RMS、超调、稳定时间、饱和占比、异常零增量、同侧误差、外部距离/转角误差和停车延迟。

可先拟定稳定中速区稳态误差≤5%、超调≤10%作为工程目标，再根据本车有效速度范围和测量精度确定正式门槛。低速使用绝对误差和计数窗口指标，避免接近零时百分比失真。整车角度精度必须使用外部基准，不能用编码器与自身运动模型的互相一致作为验收。

当前 PWM 上限300‰、命令超时、急停直接关断和换向最短保护作为初期约束。若后续需要改变，单独提供硬件依据、比较数据和验证结论。
