# 右后轮复测与 0.18.6 pivot 补偿交接

日期：2026-10-20（Asia/Tokyo）。状态更新：右后轮实板检查完成；用户已烧录 0.18.6，并完成左右各 6 秒地面对照。顿挫减轻，但低速轮速跟踪精度尚未通过。详见 [实板证据与对照](stm32_evidence/2026-10-20-v0186-powered-pivot/README.md)。下文构建与烧录步骤保留作为交付记录，不能据此视为所有实车验收项目已完成。

## 右后轮检查结果

用户反馈右后轮转速或声音与其他轮不同。四轮架空、电池接通后，RR 与 LR 在相同 15% PWM/800 ms 条件下正反向各重复三次，全部启动和完成。RR 正向计数增量 763/775/776，反向 -737/-745/-752；LR 正向 765/760/764，反向 -793/-815/-831。

单轮闭环 ±500 cps/4 秒对照：RR 后 2 秒平均 +519/-508 cps，LR +509/-508 cps。RR 最大 PWM 150‰，LR 正反向最大 PWM 136/140‰。用户现场确认转动连续、只是声音不同。当前未见方向错误、反馈中断或闭环明显失控；声音差异未经录音分析，无法据此排除或确认机械问题。

详细数据与原始日志见 [RR/LR 实测证据](stm32_evidence/2026-10-20-v0185-rear-check/README.md)。这些是旧板上 0.18.5 的检查，不是新固件实车验证。

## 为什么修改

[有电池地面左右转实测](STM32_V0185_POWERED_PIVOT_REVIEW_20261020.md)表明：请求/应用稳定为 ±200 mrad/s，四轮目标 ±160 cps，但轮子存在停转区间。60‰ 启动补偿在阈值处退出，PI 来不及接管，该轮停转后再次触发补偿，形成周期性起停。

0.18.5 的迟滞和最短保持时间不能消除上述现象。末段平均轮速接近目标，不能作为平顺性通过依据。

## 0.18.6 实现

版本：`0.18.6-pivot-bumpless-handoff`。

启动补偿投入条件、60‰ 幅值、300 ms 最短保持时间和 20/50 cps 迟滞阈值沿用现值。改变的是退出交接：

```text
combined = old_integral + old_pivot_bias
new_integral = clamp(combined, -50, +50)
remaining_pivot_bias = combined - new_integral
```

下一次 PI 更新立即使用剩余补偿，所以同一目标和测量条件下，退出瞬间的“前馈 + 积分”不变，不会因为退出而凭空撤走 60‰。

当积分到达限制时，容纳不下的部分继续作为本次 pivot 的局部负载支撑；真实速度误差通过正常 PI 积分逐步调整总支撑。超速误差可以让剩余补偿退出，不会把它固定为永久 PWM 下限。停车、换向、退出 pivot 或零轮速目标会清理该 pivot 局部状态；正常输出仍受原有斜率/幅值限制。

例如，负向轮旧积分 -43‰、旧补偿 -60‰：交接后积分为 -50‰、剩余补偿为 -53‰，合计仍为 -103‰。没有直接把积分上限改到 103‰，也没有额外再加一份 60‰。

保留：KP=0.05、KI=0.25、积分限制 ±50‰、PWM 限制 ±300‰、输出斜率 1000‰/s。未修改 CubeMX、编码器映射、PWM 频率、USB 协议、IMU 或校准存储。

- `Application/Chassis/chassis_controller.c`：每轮保存已应用补偿；退出时执行交接；生命周期清理。

## 用户烧录后的验收

1. 烧录期间关闭电机 VM，按既有全片擦除流程操作，恢复用户 Flash 启动。确认 Banner 为 `0.18.6-pivot-bumpless-handoff`。
2. 全片擦除会清掉既有 IMU Flash 校准；IMU 协议和校准逻辑本轮没有改变，需按既有显式流程重新校准/保存后再用于 ROS 融合。
3. 先检查启动安全状态、只读 STATUS、四轮静止和供电。未取得用户当前测试条件确认前，不发送运动命令。
4. 地面采用与基线相同的 ±200 mrad/s、6 秒左右转向，保持 CH340 连接，停止后完整读完 128 帧再开始另一方向；同时记录全程 USB 原始计数和供电。
5. 比较近零原始计数区间、峰值与速度波动、补偿释放时 PWM 连续性、启动阶段欠速及左右差异，不能只比较平均轮速。若仍有起停，继续分析负载、供电及前馈工作点，不预先认定修复成功。
6. 回归显式 STOP、250 ms 命令超时和断链停车；只有实测符合要求后再向 ROS 工程师标记可验收版本。
